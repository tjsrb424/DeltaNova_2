# 기지 운영과 단독 진행 검증 2026 10 13

기지 생산과 시설 투자, 보급 출격 비용, 귀환 성과와 정비, 연구 모듈을 참가자별 서버 장부에 연결했다. 개인 작전은 혼자 성장하는 경로이며 공동 작전도 같은 참가자가 네 역할을 순서대로 완료할 수 있다. 협동은 역할과 비용을 나누는 선택이다.

## 구현

- 제조라인/합성소 레벨1..3, 분 단위 생산, 저장 상한, 접속 공백 최대8시간, 역행 시각 보호. 화면 예상량과 서버 확정 기록을 구분한다.
- 개인 출격 지휘 합계+지원2 보급, 화물×4 합금, 최고 성과 증가분 연구. 귀환 1회 정산과 손실 HP10당 합금1의 완전 정비.
- 개인·공동 출격에 같은 함대 정비와 기지 활성 모듈 적용. 개인 출격 중 공동 기여와 정비 차단.
- 완료 역할이 다음 예약을 막지 않고 공동 성공은 고유 기여자당 한 번. 단독 네 역할60공헌/네 명 각각30.
- 공유 저장 v2와 개인 GameState v1 재사용. 기존 공동 상태·모든 영수증 응답은 한 트랜잭션에서 이전하고 요청·revision·공헌·소유권 보존.
- 기지 운영 메뉴와 생산·시설·정비·연구·개인 관제. 기존 브라우저 편성 연습 저장 보존. 비용 없는 연습과 서버 성장의 구분을 화면·README에 표시.

## 증거

`npm test`: 9개 파일96개 통과(기존73+경제규칙11+서버/이전5+기지DOM6+서버 화면 표시1). `npm run build`: 타입 검사와 production build 통과. `verify:build`는 빌드 HTML/JS/CSS/기지 아트 HTTP 제공, `verify:guild`는 Vite proxy→API→SQLite로 협동 완료 후 같은 참가자의 네 역할·정비·보급 순차 완료와 공헌60/고유 성공 보상1회를 확인했다. 임시 서버를 종료했다.

순수 테스트는 시간/상한/소급 생산, 투자 거절 불변성, 출격·귀환·보고서 닫기의 정산 경계, 무력화 복구, 개인 연구, 단독 네 역할의 고유 보상을 확인한다. 서버 테스트는 실제 SQLite 이전·이전 중 쓰기 거절/손상 영수증 롤백·기존 명령 재전송·HTTP 개인 출격/정비/연구/재시작을 확인한다. DOM은 생산·투자·혼자 작전·정비·연구·부족 비용 차단·참가자 전환·다음 역할 예약·미확정 투자 재진입을 확인한다.

독립 코드 검토를 완료했다. 증설 직전 미완성 생산을 새 생산률로 소급 계산하던 문제와 서버 화면에 연습 연구/모듈을 표시하던 문제를 실패 재현 후 수정했다. 59,999ms 증설 후 60,000ms 합금86, 다음 분98; 가득 찬 저장고와 8시간 상한 뒤 증설은 버린 생산을 되살리지 않는다. 생산 나머지는 현재 시설 생산률에 맞는 정수 범위를 검증한다. 검토 후 한 번의 수정 단계에서 전체 테스트·빌드·HTTP 검증을 통과했다. 재검토는 수행하지 않았다.

브라우저·에디터·렌더러 창을 열지 않았다. 실제 렌더와 모션 체감, 장기 경제와 유저가 느끼는 재미는 자동 검사로 확정하지 않는다. 고정 개발 함대9척이고 조선·함종 확장·실제 계정과 서비스 운영은 다음 단계다.

## 결정

판단과 추후 비용을 순서대로 기록한다.

1. 추천안 위임에 따라 추가 승인 없이 설계·구현: 방향이 다르면 로컬 설계와 코드 수정 비용.
2. 기존 전용 브랜치·작업 공간 유지: 동시 작업이 생기면 작업 공간 분리 비용.
3. 기존 브라우저 연습 기록 보존, 새 서버 성장 추가: 향후 명시적 진행 가져오기와 UI 통합 비용.
4. 검토에서 보류한 연습 진행 자동 이전은 3번 결정을 유지: 이후 가져오기 설계 비용.
5. 실제 계정·인터넷 운영은 후속 범위: 인증·호스팅·운영 구현 비용.
6. 렌더와 모션 체감 검증은 창 실행 요청 시 진행: 그때 확인되는 화면 수정 비용.
7. 장기 경제·함종 확대는 후속 개발: 밸런스 조정과 조선·함종 구현 비용.
8. 참가자 변경 시 공동 화면의 선택 편성은 입력 선호로 유지: 현재 동일한 보유 함대와 서버 재검증으로 비용·정비·출격 주체가 바뀌지 않음. 서로 다른 보유 함대 도입 시 편성 초기화/재검증 비용.
9. 이번 계획의 gitignored 검토 임시 기록은 보존: 향후 로컬 정리 비용. 제품 저장과 별개다.

서버 화면의 연습 연구/모듈 표시는 사용자 판단을 잘못 이끌 수 있어 검토의 Minor에서 Important로 높이고 수정했다. 미해결 Critical/Important 및 보류한 Minor는 없다.
