# DELTA NOVA — UI/UX REFOUNDATION KIT v1.0

**작성일:** 2026-10-15  
**상태:** 제안 / 미적용 / 코드베이스 미확인  
**핵심 방향:** Minimal Galactic Command  
**사용 대상:** Codex 및 Delta Nova 개발·디자인 작업

> 이 패키지는 현재 저장소를 직접 검사하지 않은 **설계 입력물**이다. 프로젝트의 실제 기술 스택, 데이터 구조, 기존 UX가 이 문서와 다를 수 있다. Codex는 먼저 진단하고 충돌을 보고해야 하며, 게임 규칙이나 데이터를 임의 변경해서는 안 된다.

## 핵심 결정

- 개별 화면을 감각적으로 반복 제작하는 방식은 **중단**. 공통 디자인 언어를 먼저 확정.
- **Linear / Geist 수준의 명료한 정보구조** + **우주 게임의 시각적 몰입** + **절제된 인터랙션**을 결합.
- 중앙의 행성을 **성장에 반응하는 핵심 시각물**로 유지하되 게임 상태를 가리지 않을 것.
- 평상시 화면은 차분하고, **적 함대 접근·건설 완료·긴급한 결정**에서만 높은 연출 강도를 사용.
- 기존 경제·정찰·약탈·복수·외교·PvP 밸런스·BM·서버 계약은 UI 개편 범위 밖.
- 먼저 대표 화면 3상태(평상시/적 접근/행동 완료)의 품질을 검증한 후 확장.

## 패키지 경계

- 포함: 설계 문서, 초기 시맨틱 토큰(JSON/CSS), 샘플 프로토타입, 테스트 시나리오, 체크리스트, 리포트 형식, 출처 링크.
- 미포함: 실제 저장소의 코드·API 스키마, 게임 규칙 검증, 확정된 아트 에셋, 외부 폰트, 확정 시안 이미지, 실제 3D 모델.
- 07_PROTOTYPE는 **프로덕션 품질의 행성 렌더러가 아니라 레이아웃·인터랙션 의도 시연**. 샘플 숫자/레이블과 상호작용은 운영 로직이 아님.

## 빠른 사용법

1. ZIP을 풀고 `README.md`와 `CODEX_PROMPT.txt`를 읽는다.
2. 이 폴더를 코드 저장소의 `docs/uiux-refoundation/` 같은 위치에 추가하거나 Codex가 읽을 수 있는 별도 참조 폴더에 둔다. **기존 파일을 덮어쓰지 않는다.**
3. Codex를 해당 저장소 루트에서 실행하고 `CODEX_PROMPT.txt`의 지시문을 전달한다.
4. 첫 실행에서는 **저장소 진단 + 위험 목록 + 바이블 충돌 조정 + 분리된 시연물**까지 수행한다.
5. 사용자가 결과를 승인한 다음에만 메인 UI 통합과 페이지별 이관을 진행한다.

## 공통 완료 조건

- 게임 로직/수치/네트워크 계약은 무단 변경 없음.
- PC 1920×1080, 1440×900 / 모바일 390×844, 360×800에서 주요 기능 노출 및 오버플로 없음.
- 키보드·터치·모션 감소·적 접근 이벤트에서 동작 검증.
- UX 테스트 과제 전부 성공, 치명적 접근성 실패 0건.
- 시각·정보·조작성·모션·성능 종합 평가 **9.5/10 목표**. 심미 점수 단독으로 통과 불가.
