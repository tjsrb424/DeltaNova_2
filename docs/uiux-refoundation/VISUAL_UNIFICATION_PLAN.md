# 데모 전체 그래픽·모션 통일 계획

2026-10-16 · 기준766b248 · `codex/demo-visual-unification`

직접 승인한 함대 화면을 시각 기준으로 삼아 기존 독립 데모의 표현을 맞춘다. 정보 구조·게임 수식·데이터 계약을 바꾸는 작업은 아니다. 데이터 연동과 실제 서비스 UI 교체는 진행하지 않는다.

## 화면별 적용

| 화면 | 아트/픽토그램 | 모션 목적 |
|---|---|---|
| 행성 관제 | 기존 자연 행성 보존, 시설별 고품질 썸네일·공통 네온 아이콘 | 시설 선택, 위협/완료 피드백의 원인 전달 |
| 건설·시설 상세 | 6종 시설 아틀라스, 선택 시설의 큰 아트 | 선택과 현재 비교 대상 연결 |
| 연구 | 연구소 아트와 차분한 연구 배경 | 기존 예시 진행의 단일 주사선, 수치 자체는 불변 |
| 함대·출항 | 기존 함선 아트, 정확한 함종/척수의 네온 편대, 항로/목적지 표식 | 대기·출항·도착·귀환·주둔 단계 구분 |
| 방어·회피 | 자연 행성+방어/접근 네온 표식 | 현재 위협 유무와 선택 행성 구분 |
| 출격·은하 | 공간 배경·행성 텍스처·선택 대상 표식 | 대상 선택과 수동 정찰 시연만 반응 |
| 동맹 | 기존 관문 아트 검토·보완, 참가 함대 표식 | 공동 도착 비교, 자동 출항 없음 |
| 보고서·전체 메뉴·외교·랭킹·설정 | 공통 고품질 픽토그램, 비어 있음/미연결 상태의 차분한 그래픽 | 선택·초점·진입 피드백, 가짜 콘텐츠/성과 없음 |

## 그래픽 채택 게이트

생성 후보를 곧바로 제품 폴더에 넣지 않는다. 원본 크기와 실제 표시 크기로 검토하며, 발견한 형태 오류·AI처럼 보이는 잔선/무의미한 부품·비대칭·잘림·텍스트 흔적을 기록한다. 필요하면 재생성/편집 후 재검토한다.

평가는 내부 시각 판단이다. 자동 AI 노이즈 탐지나 객관적 인증으로 표현하지 않는다. 실루엣/구조3점, 청결도2점, 스타일 일관성2점, 표시 크기/구도2점, 투명도/실행 비용1점의 합계10점. **9.5점 초과**이면서 중요한 형태/잘림/노이즈 결함이 없어야 채택한다. UI 전체 점수는 별도의 UX·접근성·성능 평가로 관리한다.

네온은 전체 텍스트를 빛내는 장식이 아니라 항로·선택·상태의 시각 언어다. 평시에는 절제하고, 사용자의 편집/선택/출항/완료 시연에서만 강한 반응을 준다. 장식 이미지/픽토그램에는 숫자나 실제 결과를 굽지 않는다.

## 검증·전달

기존 기능과 직접 편성 유지, 함종별 네온 척수 일치, 행성/시설 선택 연결, 미연결/빈 상태, 이미지 실패, 입력 초점, Back, 모션 감소·수동 정지·비가시 상태를 검사한다. 데스크톱·태블릿·390/360/320px·가로·200% 글자로 모든 데모 메뉴를 확인한다. 원본/프롬프트/채택 기록/캡처/테스트/인수인계를 커밋·푸시한다. 기존 작업은 보존한다.
