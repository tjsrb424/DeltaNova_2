# 함대 운용 중심 UI/UX 방향

2026-10-16 · 사용자가 확인한 방향으로 서버 미연결 데모를 재구성한다.

후속 사용자 지시에 따라 명령 화면의 프리셋 시작점을 폐기하고, 빈 편성에서 8함종을 직접 선택하도록 변경했다. 최신 기준은 [자유 편성 설계](./FREE_FLEET_DESIGN.md)와 [검수 보고](./FREE_FLEET_REVIEW.md)다. 아래 설명 중 추천 시작점과 커밋 보류는 이전 실행 당시의 이력이며, 후속 변경은 별도 브랜치로 커밋·푸시한다.

기본 행동은 목표를 고르고 함대를 보내 전투하는 것이다. 깊이는 목표·출발 시점·함대 이동·잔류 방어·동료와의 도착 시각·함대 조합에서 나온다. 자동 출발과 역할별 별도 임무는 기본 플레이에 강제하지 않는다.

## 이번 데모 범위

1. 출격: 공격/정찰/이동/증원 → 목적지 → 공통 함대 명령. 개인 작전의 이야기 목록에서 편성 연습으로 넘어가는 강제 흐름을 교체한다.
2. 함대 명령: 추천은 시작점이며 직접 편성 가능. 출발 지연을 사용자가 선택하고 도착 시각·연료·잔류 함대를 먼저 확인한다. 조합은 전력·기동·화물의 예시 값에 연결한다.
3. 동맹: 공동 목표·참가 함대·예정 도착을 표시한다. 같은 명령 화면으로 합류하며, 도착 시각 맞추기는 사용자가 누르는 선택이다. 자동 출발하지 않는다.
4. 은하의 선택 대상, 함대 시연 목록, 방어 대응에서도 같은 명령 흐름으로 진입한다.
5. 명령 확인 → 출항/대기 → 도착의 로컬 장면 시연. 공격·정찰은 귀환하고 이동·증원은 현지에 주둔하며 직접 귀환을 선택한다. 실제 자원·함선·서버를 변경하지 않는다. 시연 함대끼리만 가용 편성을 계산해 중복 배치를 막는다.
6. 기존 편성 연습은 선택적인 실험실로 보존한다. 필수 출격 단계로 사용하지 않는다.

## 검증

순수 모델의 편성·목적지 조건·시각·예약·귀환·초기화, DOM의 선택/뒤로 가기/초점/검토 무효화를 검사한다. 데스크톱·390·320·가로 화면·200% 글자 확대에서 직접 확인한다. 공유 HTTPS 주소에서 그림과 명령 흐름을 재검증한다. 게임 API/DB/운영 소스는 변경하지 않는다.

## 실행 구분

순수 시연 모델과 테스트는 별도 구현 작업으로, 화면·기존 컨트롤러 통합·모바일 검수는 주 작업에서 진행한다. 마지막에 별도 읽기 전용 리뷰와 전체 회귀 검증을 수행한다. 기존 작업과 브랜치를 유지하고 커밋·푸시는 수행하지 않는다.
