# 게임 용어·데모 안내 정리 — 2026-10-16

사용자 요청: 개발자식 문구를 전체적으로 게임 용어로 바꾸고, 데모 안내를 별도로 정리한다. 독립 데모에서 모바일·접근성을 검증한 뒤 main에 커밋·푸시한다. 데이터 연동과 실제 서비스 UI 교체는 하지 않는다.

기준 커밋: `17864b2cf0ba31ef8c5a72a5ac8daa20a0b19fac`. 기존 개발 worktree와 원래 체크아웃을 보존한다. 아래 기준은 새 게임 규칙이 아니라 화면 언어 기준이다.

## 문구 기준

- 버튼은 누른 뒤 할 일을 말한다. ‘검토·전송·실행·계획’ 대신 ‘건조·연구·취소·이동·확인’을 사용한다.
- 첫 버튼은 ‘함선 건조’ 또는 ‘연구하기’, 확인창의 최종 버튼은 ‘건조 시작’ 또는 ‘연구 시작’이다. 취소 버튼은 건설·연구·건조별 이름을 쓴다.
- 비용·보유량·환급 설명에는 게임 안의 의미를 쓴다. ‘지불·미반환·원 지불 행성’ 대신 ‘사용한 자원·돌려받지 못하는 자원·환급받을 행성’을 쓴다.
- ‘미연결·스냅샷·로컬·피드백·준비안’을 플레이 화면의 상태나 행동 이름으로 쓰지 않는다.
- 예시 이동·관측을 생성하는 버튼에는 ‘미리보기’를 유지한다. 실제 명령이 전송되는 것처럼 표시하지 않는다.
- 데이터가 없는 화면은 확인할 수 없는 이유를 짧게 설명한다. 정비·전투·메시지·순위에 가짜 결과를 넣지 않는다.

## 별도 데모 안내

상단의 ‘디자인 데모 / 예시 데이터 · 실제 게임에 반영되지 않습니다’는 모바일에서도 유지한다. ‘데모 안내’ 버튼은 기존 안내·설정 disclosure를 열고 summary로 포커스를 옮긴다. 안내에는 데이터 출처, 최종 명령 비활성, 이동·관측 미리보기, 진행률·시간 고정 값, 임시 화면 한도를 설명한다.

공통 화면 아래는 ‘데모 조건’, 연구 수준 선택은 ‘데모 조건 바꾸기’, 취소창의 상황 선택은 ‘데모 조건’ fieldset으로 구분한다. 시설·연구·함대·정찰 카드마다 반복하던 구현 설명은 제거했다. native dialog에는 별도의 짧은 데모 안내를 두어 배경이 inert가 되어도 설명을 읽을 수 있다. 비활성 명령의 aria-describedby는 해당 안내를 가리킨다.

## 검수 중 발견해 수정한 문제

1. 320px·200% 글자 확대에서 안내 드롭다운 하단이 고정 메뉴에 가렸다. 캡처로 발견했으며 열린 안내의 표시 순서를 높였다. 마지막 안내 버튼 중앙에서 elementFromPoint로 실제 클릭 대상까지 확인한다.
2. 함대 이동 단계가 수동으로 바뀌는데 ‘귀환을 기다리세요’라고 설명했다. ‘함대에서 귀환 미리보기를 완료하거나 출발 행성을 바꾸세요’로 수정했다.
3. 시설 상세의 비활성 ‘건설 시작’에 설명 연결이 빠져 있었다. 모달 내부 dialog-demo를 연결했다.
4. 상단 안내 버튼과 기존 안내 행이 모바일 세로 공간을 중복 사용해320×568에서 건설 버튼 하단이 메뉴에8.4px 가렸다. 모바일에서는 닫힌 안내 행을 숨기고 상단 버튼을 단일 진입점으로 사용한다. 안내를 닫으면 상단 버튼으로 포커스를 돌려준다. 기존 행동 위치 검사의12px 여유 기준을 그대로 검증한다.
5. 새 버튼 이름과 안내 위치에 맞게 기존 검수를 갱신했다. 숫자·수식·가용 함선·원 지불 행성·자원 불변·비활성 검사와 포커스 검사는 유지한다.

## 검증 근거

최종33파일·341테스트, 빌드·빌드 검증, headless 검사70개가 통과했다. 문구 전용69개·연구/건조24개·통합15개 레이아웃 검사, 확인창20조건 AX 검사를 포함한다. 최종 결과와 원문·캡처·재현 명령은 [QA 기록](../qa/2026-10-16-game-language/README.md)에 정리한다. 실제 휴대폰·VoiceOver/TalkBack 음성 검수는 별도이며, Chromium 모바일 에뮬레이션·접근성 트리·키보드 검수와 구분한다. 문구 명확성은 내부 검토 결과이며 실제 신규 사용자 이해도 측정 결과로 제시하지 않는다.

## 이렇게 테스트하세요

1. 독립 데모의 함대 화면에서 ‘함선 건조하기’를 누른다. 함종과 수량을 골라 ‘함선 건조’를 누르면 ‘건조 시작 전 확인’이 열린다. 최종 ‘건조 시작’은 비활성이다.
2. 연구에서 ‘연구하기’를 누르고 효과·자원·연구소 조건을 확인한다. 각 작업 목록의 ‘건설 취소·연구 취소·건조 취소’를 눌러 환급받을 행성과 자원별 환급액을 확인한다.
3. 상단 ‘데모 안내’를 키보드 Enter로 열고 320px·200% 글자 확대에서 내용을 끝까지 스크롤한다. Escape로 확인창을 닫으면 누른 버튼으로 포커스가 돌아오는지 확인한다.
4. 출격의 ‘출항 미리보기’, 은하의 ‘정찰 정보 미리보기’가 예시로 동작하며 최종 실제 명령을 보내지 않는지 확인한다.
