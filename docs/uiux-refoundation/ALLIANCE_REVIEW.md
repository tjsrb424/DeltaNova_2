# 동맹 · 공동 작전 데모 검수

2026-10-16 · `codex/uiux-refoundation` · 로컬 미커밋 변경

## 반영한 화면과 흐름

- 기존 `guild` 중앙 메뉴의 준비용 안내를 오로라 협약 현황, 4명의 고정 참가자, 도약문 재가동 공동 목표, 4개 역할과 기여 정보로 구체화했다.
- 역할 선택 → 같은 화면의 준비 영역 → 행성별 역할 추천/타격함 비교/빈 편성 → 로컬 준비안 검토 → 수정 흐름을 제공한다. 오른쪽 패널은 추가하지 않았다.
- 정찰·교란·보급의 완료 지원과 돌파를 구분했다. 완료된 준비 지원은 돌파에 도움을 주며, 모든 지원을 갖춰야 돌파할 수 있는 것처럼 표시하지 않는다.
- 완료 역할과 다른 참가자가 준비 중인 역할은 기여 조건을 열람할 수 있지만 내 준비안 검토는 제한한다. 필요한 함종이 빠지거나 현재 행성에 함선이 없으면 복구 방법을 함께 안내한다.
- 상황 선택기로 기여 준비 중, 준비 지원 확보, 공동 목표 달성의 고정 예시를 비교한다. 참가자 접속 상태나 실시간 예약 만료 시간을 만들어 표시하지 않는다.
- 준비안 검토 결과는 선택 행성·역할·함선 수·지휘·화물·완료 지원을 담는 고정 스냅샷이다. 역할/상황/편성/행성/오프라인 상태를 바꾸거나 초기화하면 이전 검토를 폐기한다.
- 역할 URL `#view=guild&role=breach`를 검증해 읽고 Back/Forward로 복원한다. 실제 게임 자산·저장소와 연결하지 않는다.

## 직접 보며 개선한 부분

- 초기 모바일 레이아웃은 동맹 요약이 길어 준비 동작을 찾기 어려웠다. 요약 수치를 한 줄로 압축하고 삽화 위에 44px 높이의 ‘내 역할 준비’ 버튼을 배치했다. 390×844 첫 진입 화면에서 하단 메뉴 위로 버튼이 보이는지 자동 검사한다.
- 모바일과 태블릿의 준비 영역에 역할 선택기를 추가했다. 다른 역할을 비교할 때 위쪽 역할 카드까지 되돌아가지 않아도 된다.
- 카드의 상태는 색상과 문자로 함께 표시한다. 선택된 역할에는 테두리와 ‘선택됨’ 문구를 제공한다. 역할 카드는 4열에서 2열로 바뀌며, 준비 영역은 작은 화면에서 한 열로 재배치된다.
- 역할 카드에서 진입하면 준비 제목으로, 검토하면 결과 제목으로 초점을 옮긴다. 편성 다시 보기에서는 검토 버튼으로 돌아간다. 선택기 변경과 Back에서는 선택기의 초점과 스크롤을 유지한다.
- 200% 글자 확대에서 긴 영문 보조 문구가 많은 줄을 차지해 ‘내 기여 · 노바’로 줄였다. 헤드라인·설명·조건·선택기는 줄바꿈하며 가로 넘침이 없다.
- 새 도약문 삽화는 장식 배경으로 사용하고, 제목과 행동은 HTML로 유지한다. 동맹 문장과 역할 4종은 직접 작성한 SVG다. [아트와 최종 프롬프트](./ALLIANCE_ART.md).

## 확인한 근거

- `npm test -- --maxWorkers=2`: **28개 파일 · 284개 테스트 통과**. 최초 기본 동시 실행에서는 7개 worker가 시작 응답 제한 시간에 걸렸다. 실패 원인이 테스트 단언이 아닌 worker 시작 단계임을 확인하고, 동시 실행 수를 줄인 전체 재실행으로 통과했다.
- `npm run build`, `npm run verify:build`, `git diff --check`: 통과.
- `node tools/verify-uiux-polish.mjs`: 최종 문구 변경 후 **35개 통합 검사 · 기존 행성 15개 배치 검사 통과**, 기록한 API 요청·스토리지 접근·런타임 오류 0.
- 동맹의 개요·준비 영역: 1440×900, 839×1065, 390×844, 320×568, 844×390. 가로 넘침, 글자 대비, 터치 영역, 그림 로드, 중앙 메뉴 유지 확인.
- 320/390/844 폭에서 200% 글자 확대. 실제 본문 글꼴 크기가 13px→26px로 변하는지 확인한 뒤 넘침과 대비를 검사했다.
- CUA로 열린 Chrome 데모에서 데스크톱, 390×844, 320×568, 844×390을 직접 보았다. 역할 변경, 필요한 함종 누락 안내, 추천 편성 복원, 검토 결과, 수정 동작과 모바일 하단 메뉴를 확인했다. 최종 뷰포트는 원래 크기로 복원하고 동맹 화면을 열어 두었다.
- 별도 컨텍스트의 읽기 전용 코드 검토: 상태·초점·이력·서버 분리에서 구체적인 결함 발견 없음. 해당 검토는 실기기 검증을 대신하지 않는다.

## 서버 분리와 한계

게임 API 4318의 리스너 0, `.delta-nova/guild.sqlite` 없음, `src/` 변경 없음. `dev:solo` 정적 데모만 사용했다. 실제 동맹 예약·기여·출격·보상은 전송하지 않는다. 일반 테스트의 임시 서버/임시 저장소는 테스트 격리 환경이며 게임 서버 연결이 아니다.

모바일 확인은 Chrome 반응형 뷰포트이며 실제 iOS/Android 기기를 사용하지 않았다. 참가자·상황·보상·기여는 예시로, 실제 네트워크 동시 참가·전투·경제 정확성은 이번 검수 범위에 포함하지 않는다. 커밋·푸시·배포는 수행하지 않았다.
