# 건설·방어 카탈로그 v0.1

추천 수치의 원본은 [catalog.mjs](catalog.mjs), 계산식·검증 도구는 [audit.mjs](audit.mjs)다. 런타임 가격이나 기존 저장을 변경하지 않는다. 비용 열은 합금 / 결정 / 연료 순서다.

## 방어 설비

함선과 별도인 현지 방어 건조 라인 1개를 추천한다. 설비 한 기는 공간 1을 차지한다. 포대는 공격 없이 상대를 무상 파괴하지 않으며, 주둔 함대와 공성의 상성 검증을 함께 진행한다.
