# 개인 작전·편성 연습 디자인·모바일 검수

2026-10-15 작업 시작 · 2026-10-16 최종 검수 · `codex/uiux-refoundation` · 로컬 미커밋 변경

## 화면과 사용 흐름

기존 중앙 작업 화면의 어두운 색상·카드·선 아이콘·짧은 이동 방식에 개인 작전과 편성 연습을 맞췄다. 주요 화면은 중앙에서 전환하며 새 모달 단계는 추가하지 않았다.

개인 작전은 고요한 잔해지대, 봉쇄된 중계 거점, 새벽 수송선단의 3개 브리핑을 제공한다. 목표·고려할 위험·추천 역할·준비 흐름과 현재 편성의 기본 준비 상태를 구분한다. 선택한 작전은 편성 연습으로 이어지며 URL과 브라우저 Back에도 반영된다. 준비 버튼은 긴 설명 아래에 묻히지 않도록 브리핑 삽화 안에 배치했다.

편성 연습은 케스트럴·바스티온·랜서·멘더·아틀라스·위스프·베일·아크의 8종 예시 함선을 제공한다. 노바의 보유량은 10척, 베스퍼는 0척으로 기존 데모 요약과 맞췄다. 함종별 수량, 균형·회수·거점 대응 예시 편성, 지원과 접근 방식을 비교한다. 편성 함선 수·지휘·화물·역할이 함께 바뀐다.

수량은 함종별 보유량 안으로 제한하며, 전체 6척·지휘 12의 예시 기준을 넘긴 구성도 살펴볼 수 있다. 초과 수량과 줄일 지휘량, 우회에 필요한 위스프 또는 정찰 지원을 구체적으로 안내한다. 작전별 추천 역할은 필수 준비 조건과 구분한다.

검토 버튼은 현재 편성의 준비 조건만 메모리 안에 보존한다. 실제 전투 승패·보상·소요 시간은 계산하지 않는다. 이후 수량·지원·접근·작전을 바꾸거나 다른 행성으로 이동하면 이전 검토 결과를 지운다. 행성별 연습 편성은 따로 유지하며 실제 자원과 함선 재고는 변하지 않는다. 실제 출격 버튼은 항상 비활성이다.

## 직접 검수하며 보완한 부분

- 모바일 함선 카드를 약 145px 높이의 간결한 구성으로 정리했다. 역할·함선 도해·지휘·화물·보유량·수량은 유지하고 반복되는 영문 이름과 설명을 줄였다.
- 모바일 상단의 반복 행성 배지와 수량 안내를 덜어 실제 조작까지의 스크롤을 줄였다. 긴 편성 목록에는 요약 이동 버튼을 제공한다.
- 수량 입력 요소를 유지한 채 요약만 갱신한다. 유효한 수량은 입력 중 바로 반영하며 빈 입력·범위 밖 값은 확정 시 정상화한다.
- 검토 버튼을 갱신 영역 밖에 유지했다. 숫자 입력을 마친 직후 누르는 첫 클릭이 재렌더로 사라지지 않도록 했다.
- 수량이 보유 한도에 도달해도 증가 버튼의 키보드 초점이 사라지지 않게 했다. 보유량이 아예 없는 행성에서는 관련 조작을 비활성화한다.
- 검토 결과와 요약 이동은 카드 전체가 여백과 함께 보이도록 하고 제목에 초점을 맞춘다. 결과 닫기는 검토 버튼으로 초점을 돌려준다.
- 작전 → 편성 연습 → Back에서 선택한 작전, 진입 조작의 초점과 스크롤을 복원한다.

직접 본 결과 새 삽화와 함선 도해가 기존 행성·은하 화면의 색상과 여백에 잘 맞는다. 작전에서는 다음 행동을, 편성에서는 역할과 수량을 먼저 읽을 수 있도록 정보 우선순위를 정리했다.

## 새로 제작한 시각 자료

내장 image_gen 도구로 조용한 탐사 함선·궤도 중계 시설·행성 가장자리의 삽화를 새로 생성했다. 전체 구도를 유지해 WebP로 변환했으며 런타임 파일은 **62,360bytes, 1536×1024**다. 함선 도해 8종과 역할 선 아이콘은 독립 SVG로 작성해 크기에 따라 선명하게 표시한다. 모든 수치·버튼·라벨은 실제 HTML이다.

원본·최종 경로, 사용 방식과 최종 생성 프롬프트는 [아트 제작 기록](./OPERATIONS_ART.md)에 보존한다.

## 최종 검증

- `npm test -- --maxWorkers=2`: **27파일·275/275 통과**.
- `npm run build`: TypeScript 검사와 정적 빌드 통과.
- `npm run verify:build`: 정적 산출물 제공 검사 통과.
- `node tools/verify-uiux-polish.mjs`: **32개 통합 검사 통과**, 기존 행성 관제 15개 상태·크기 조합도 통과.
- 작전·편성 각각 1440×900, 839×1065, 390×844, 320×568, 844×390에서 가로 넘침·텍스트 대비·44px 수량 조작 영역 검사 통과.
- 320/390/844px의 200% 글자 검사에서 준비 결과와 내비게이션이 reflow하며 가로로 넘치지 않는다. 새 `rem` 글자도 실제 두 배가 되도록 검수 도구를 보완했다. 작전 본문 12→24px, 함선 역할 10→20px를 기준 크기와 비교한다.
- 자산 불변, 행성별 편성 유지, 오래된 검토 결과 제거, 입력과 검토 버튼 DOM 유지, 첫 클릭, 초점·Back 복귀, 오프라인 가림·초기화, 중복 ID 검증 통과.
- 별도 읽기 전용 코드 검토에서 남은 Critical/Important/Minor 지적 없음. 새로운 런타임 오류·게임 API·비GET 요청·Storage 접근 0건.

Chrome 반응형 모드에서 390px·320px·844px를 직접 조작하고 캡처를 보며 검수했다. 실물 iOS/Android 기기 검수나 전체 WCAG 인증을 뜻하지 않는다. 캡처·JSON·파일 해시는 [검수 근거](../qa/2026-10-16-operations/)에 보존한다.

검수 도구의 초기 실패는 삽화 리소스 타이밍 대기, 서로 다른 텍스트 추출 방식의 비교, 일시정지 직후 합성 프레임 비교에서 발생했다. 이미지의 실제 디코딩 상태, 같은 방식의 자산 비교, 정지 프레임 안정화를 검사하도록 수정했다. 최종 전체 실행은 종료 코드 0이다.

## 변경 범위

`public/uiux-demo/operations.js`·`operations.css`와 기존 데모 진입·탐색을 연결했다. 운영 `src/`는 변경하지 않았다. 게임 서버 4318은 실행·연결하지 않았고 작업 폴더의 게임 DB도 생성되지 않았다. 모든 작전·함선·용량 값은 독립 화면 검토용 예시다. 연습 편성과 검토 기록은 새로고침·초기화로 사라진다. 커밋·푸시·배포는 수행하지 않았다.
