# 인터랙티브 프로토타입 — 구현 전 설계 예시

`index.html`을 브라우저에서 직접 열면 작동합니다. 외부 라이브러리·인터넷이 필요 없습니다.

## 시연 가능한 항목

- PC/모바일에 따라 반응하는 제국 관제 레이아웃.
- 중앙 행성의 가상의 성장 단계 4종과 단계 변경.
- `적 함대 접근(예시)` 버튼 → 명확한 위험 배너 → `회피 계획 검토` 패널.
- 회피 패널의 `검토 종료`/`실제 명령 미전송` 처리.
- `완료 상태(예시)` 버튼 → 실제 API와 무관한 시각적 완료 상태.
- 내비게이션/자원 상세 드로어 표시, ESC로 종료.
- reduced-motion 모드에서 무의미한 지속 애니메이션 중지.

## 중요한 제한

- 숫자, 시간, 자원, 비용, 성장 단계는 모두 **시각적 더미 데이터**이며 실제 게임 값이 아님.
- 실제 함대 이동, 공격, 회피 기능은 **절대 실행되지 않음**.
- 그래픽은 CSS 합성 행성. 상용 그래픽 퀄리티에 대한 확정 레퍼런스가 아니라 정보 위계/상태 전환 예시.
- 디테일을 그대로 복사하기보다는, 실제 델타노바 프로젝트에서 사용자 테스트와 렌더링 성능을 통해 조정할 것.

## 이렇게 테스트하세요

1. PC 1920×1080에서 상단/중앙/우측/사이드 구조와 액션 위계 확인.
2. `적 함대 접근 시연`을 누르고 위협 내용/회피 계획/해제 확인.
3. `성장 단계 시연`을 눌러 행성 표면/궤도 조명 변화 확인.
4. 390×844에서 자원 바·중앙 행성·행동 패널·하단 내비 겹침 확인.
5. OS 모션 감소 설정에서 행성의 계속 움직이는 효과가 중지되는지 확인.
