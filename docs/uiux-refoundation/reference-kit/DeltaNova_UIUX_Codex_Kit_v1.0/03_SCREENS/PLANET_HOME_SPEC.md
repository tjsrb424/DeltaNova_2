# 대표 화면 명세 — Planet Home / 제국 관제

## 목적

사용자에게 **현재 행성의 성장**, **자원·진행 상태**, **다음 선택**, **현재 위협**을 하나의 화면에서 인지시킨다. 주인공은 중앙 행성이고, 행동과 정보는 그 주위를 효율적으로 둘러싼다.

## 데스크톱 로파이 구조(개념)

```text
┌───────────────────────────────────────────────────────────────────────────────┐
│  로고/현재 행성   │ [자원 요약 3~5개]      [중요 이벤트] [설정/프로필]         │
├─────────┬──────────────────────────────────────────────────┬──────────────────┤
│ 홈      │  [행성명/상태]                                    │ 현재 상황        │
│ 건설    │                                                  │ ──────────────   │
│ 연구    │               중앙 행성 비주얼                    │ 진행 중 작업     │
│ 함대    │       성장별 가시적 디테일 / 대기 효과             │ 필요한 결정      │
│ 은하    │                                                  │ 1차 행동 버튼    │
│ ───     │                                                  │                  │
│ 외교 등 │  [현재 컨텍스트: 위협/건설/연구/최근 활동 요약]    │                  │
└─────────┴──────────────────────────────────────────────────┴──────────────────┘
```

이 도식은 시각적 설명이며 픽셀 퍼펙트 그리드 지시가 아니다. 1920×1080에서 주요 CTA와 위험 정보를 추가 스크롤 없이 인지시키는 것이 우선이다.

## 기본 상태(Idle)

- 중앙: 현재 행성의 2D/3D 풍부한 비주얼, 행성명, 개발 단계를 설명하는 간결한 텍스트.
- 상단: 모든 화면에서 유지되는 자원 요약과 현재 행성 컨텍스트.
- 우측: `현재 진행 중인 작업 1건` + `다음 추천 행동 1건`을 우선.
- 하단 또는 주변: 세부 정보 바로가기 (필요할 때만).
- 진행 중 작업이 없으면 빈 상태로 전환하며 무리하게 가짜 타이머를 만들지 않는다.
- 자원 수치가 실제 데이터와 연결되지 않은 시연물에는 명확한 `DEMO` 라벨.

## 위협 상태(Incoming Fleet)

- 글로벌 이벤트 경고 진입: 눈에 띄지만 UI 전체가 빨갛게 점멸하지 않음.
- 현재 대상 행성, 이벤트 유형, **검증된 서버 기준 ETA**, 위협 상세 보기, 대응 수단.
- 우측 기본 `다음 추천 행동`은 경보 대응으로 우선순위 전환하되, 평시 업무도 복구 가능.
- 화면 진입 시 자동으로 함대 이동 명령을 실행하지 않음.
- 상황 종료 시 원래 작업 화면 상태와 선택값 복원.
- 상세 동작은 `FLEET_THREAT_EVASION_SPEC.md` 참조.

## 행동 완료 상태(Action Completed)

- 서버/클라이언트 계약에 따른 실제 성공 응답 후에만 성공 토스트.
- 성공 메시지 예: `건설이 완료되었습니다` / `함대 명령이 접수되었습니다`(서버 계약에 따른 문구).
- 중앙 행성 비주얼은 실제 성장 단계의 변경 시에만 업데이트; 무관한 행동마다 성장 효과를 강제하지 않는다.
- 실패·시간 초과·서버 연결 중단은 성공과 다른 상태, 재시도 경로 제공.

## 성장 비주얼 단계(아트 가이드, 수치 미확정)

| 시각 단계 | 그래픽 차이 | 주의 |
|---|---|---|
| Early | 제한적인 표면 조명, 단순 행성 테두리 | 행성이 어두워서 UI가 읽히지 않는 문제 방지 |
| Developing | 정착지 불빛과 약한 궤도 오브젝트 | 건물 레벨 임계값 임의 규정 금지 |
| Advanced | 복수의 산업 라인, 궤도 플랫폼 | 과잉 파티클·UI 가림 금지 |
| Imperial | 높은 활동 밀도, 궤도 수송의 규모감 | 실제 게임의 기술력·경제 단계와 연결 검증 |

실제 레이어 연결은 코드베이스의 행성 건설/성장 이벤트에 대한 증거를 확보한 뒤 명세화한다. 각 단계는 아트 변형안이지 경제 수치 공식이 아니다.

## 클릭 흐름

- 자원 요약 클릭 → 자원 상세(생산, 저장, 부족 여부).
- 진행 카드 클릭 → 해당 건설/연구 상세로 진입.
- 중앙 행성 클릭 → 행성 개요 또는 행성 선택 패널. 장식 오브젝트가 스크린리더 탭 순서를 방해하지 않음.
- 위협 경보 클릭 → 위협 이벤트 상세.
- 함대 보기 클릭 → 해당 행성의 함대 정보.

## 상태 매트릭스

| 상황 | 보이는 변화 | 조작 우선순위 |
|---|---|---|
| Idle | 차분한 행성, 진행 카드 | 생산/투자/함대 |
| Loading | 스켈레톤/필요한 스피너만 | 진행 중임을 명확히 |
| Empty | `진행 중인 작업 없음`, 다음 액션 | 건설/연구 진입 |
| Threat | 위험 레이블, 이벤트 카드, ETA | 상세 보기/회피 검토 |
| Offline/Error | 데이터 갱신 실패, 마지막 성공 갱신 시점 | 재시도, 명령 제한 |
| Completed | 실제 ack 이후 완료 상태 | 다음 작업/복귀 |

## 모바일 특기

- 행성은 풀뷰를 가리지 않도록 화면 높이 약 25~40% 수준에서 반응형 조정(시안 검증 후 확정).
- 좁은 폭에서는 상단 자원 스트립이 2행 또는 수평 스크롤 가능하되, 위험 이벤트 배지 고정.
- `건설/연구/함대` 같은 핵심 경로를 바텀 내비와 겹치지 않게 제공.
- 위협 발생 시 CTA가 바텀 내비 위에 가려지지 않도록 safe area 반영.

## 성공 기준

- 기존 정보 기능 유지; 새로운 프레임에서도 타이밍/숫자 표시가 동기화.
- 사용자 테스트에서 5초 이내 `현재 상태 / 중요한 행동 / 위협 여부`를 설명하는지 관찰.
- 중요 대응 화면 진입은 PC/모바일에서 화면 복귀 없이 가능한지 검증.
