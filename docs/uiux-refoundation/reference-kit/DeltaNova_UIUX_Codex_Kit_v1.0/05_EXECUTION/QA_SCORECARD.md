# 평가표 & 합격 기준

이 평가는 감각적 호불호뿐 아니라 사용자 행동 성공 여부를 확인하기 위한 수단이다. **9.5점이라는 숫자는 프로젝트 내부 목표치이며 품질을 보증하지 않는다.**

## 가중 평가 (10점 만점)

| 항목 | 최대점 | 합격 조건 |
|---|---:|---|
| 정보 계층/복잡성 관리 | 2.0 | 3초 내 가장 중요한 상태를 찾을 수 있고 패널 노이즈가 낮음 |
| 사용성/행동 발견성 | 2.0 | 핵심 과제 접근·복귀·위험 대응이 명확함 |
| 타이포/대비/가독성 | 1.5 | 자원 수치·진행·위험 정보 정확하게 해석 |
| 비주얼 정체성/일관성 | 1.5 | 토큰/타입/패널 언어가 화면 간 일치 |
| 인터랙션/모션 완성도 | 1.0 | 동작 원인과 결과가 분명하고 모션 감소 정상 |
| 반응형/접근성 | 1.0 | 주요 해상도·터치·키보드·포커스에 결함 없음 |
| 성능/안정성 | 1.0 | 저사양 과부하·상태 유실·불필요한 재렌더 없음 |
| **합계** | **10.0** | **목표 9.5 이상** |

## 등급 정의

- **9.5~10.0:** 목표 달성, 치명적 UX/접근성/정확성 실패가 없고 실제 작업 과제 성공.
- **8.5~9.4:** 부분 개선 필요. 병목 1~3개를 선택해 집중 보완.
- **7.0~8.4:** 구조적 결함. 장식 보강보다 정보 위계 재설계.
- **7.0 미만:** 현재 안 폐기 검토, UX 접근부터 재수립.

## 독립적인 필수 합격 조건(점수와 별개)

- 경제·전투·함대·연구·네트워크/저장 로직 무단 변경 **0건**.
- 실제 데이터 동기화 오류, 가짜 결과 확인, 중요한 오작동 **0건**.
- 키보드 탐색/접근성 치명 실패 및 필수 CTA 가림 **0건**.
- 데스크톱 1920×1080, 1440×900 / 모바일 390×844, 360×800의 크리티컬 기능 이용 가능.
- 위협/회피 검토에서 자동 실행/거짓 성공/취소 불가 오류 **0건**.
- UI 로딩 시간과 렌더링 성능은 변경 전 측정값과 비교하고 **악화 시 보고**. 기기별 구체 기준은 측정 후 확정.

## 5가지 사용자 과제

| 과제 | 성공 기준 | 관찰 지표 |
|---|---|---|
| A. 현재 행성의 주요 자원 확인 | 총량과 생산량을 혼동하지 않음 | 발견 시간, 오해 |
| B. 건설/연구 진행 확인 | 현재 진행중 작업·남은 시간 위치 파악 | 클릭 수, 오경로 |
| C. 함대 현황 열기 | 1~3동작 내 함대 화면 진입 | 과제 성공률 |
| D. 적 접근 경보에 대응 | 위협 행성/도착 시각/검토 버튼 확인 | 행동 개시 시간, 오작동 |
| E. 종료·복귀 | 상세 화면을 닫아 이전 행성 컨텍스트로 복귀 | 컨텍스트 유실 유무 |

시간 기준은 사용자 표본과 난이도에 따라 조정한다. 임의의 좋은 숫자를 사후에 성과로 보고하지 않는다.

## 테스트 우선순위

1. **정보 진실성 및 명령 안정성**
2. **행동 가능성과 위험 전달**
3. **키보드·터치·모션 감소**
4. **일관성·레이아웃**
5. **그래픽 품질·모션 다듬기**

## 구현 검증 체크리스트

- [ ] 기존 게임의 모든 핵심 메뉴 접근 가능.
- [ ] 행성명/좌표와 보유 자원 표시 데이터 출처 검증.
- [ ] 클릭·호버·포커스·활성·비활성·로딩·오류 처리 검증.
- [ ] 경보 중복·갱신·사라짐이 실제 eventId와 동기화.
- [ ] UI 모션이 함대/공격 ETA를 왜곡하지 않음.
- [ ] 창 크기/축소/가로·세로 이동에 레이아웃 안정.
- [ ] 중요한 텍스트와 클릭 가능한 UI의 WCAG AA 대비 점검.
- [ ] 200% 텍스트 확대와 최소 터치 대상 검증.
- [ ] reduced-motion, 키보드 ESC, Tab 순서 확인.
- [ ] console warning/errors / 성능 프로파일 / 테스트 로그.
