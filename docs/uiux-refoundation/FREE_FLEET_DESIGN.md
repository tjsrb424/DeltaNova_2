# 자유 함대 편성 · 아트/모션 보완 설계

2026-10-16 · 사용자 후속 요청을 반영한 독립 UI/UX 데모. 기존 킷은 참고 자료이며, 아래 변경은 직접 요청한 범위에 근거한다.

## 문제와 결정

기존 명령 화면은 균형 편성 5척을 자동으로 채우고, 개별 수량 입력은 접힌 메뉴에 두었다. 자유로운 조합이 가능하더라도 첫 화면의 위계가 프리셋을 권장했다. 함종마다 같은 삼각형 아이콘을 사용해 시각적인 구분도 약했다.

- 처음에는 0척. 함종 8개의 수량을 바로 표시한다. 직접 고른 수량만 확인 화면으로 전달한다.
- 명령 화면에서 프리셋 선택기를 제거한다. 선택적 편성 실험실의 기존 예시 비교 기능은 보존한다.
- 편성 비우기는 현재 행성의 초안만 지운다. 다른 행성 초안과 시연 명령은 유지한다.
- 보유량, 함선 6척, 지휘 12, 예시 연료·이동·전력 계산은 유지한다. 운영 게임 수식은 변경하지 않는다.
- 빈 편성에는 출발/도착 시각을 계산한 듯 표시하지 않는다. 함선을 선택한 뒤 기존 예시 계산을 표시한다.

## Minimal Galactic Command 구체화

함선은 웜 화이트 세라믹, 그래파이트 금속, 제한된 시안 조명으로 통일한다. 타격·호위·공성·수리·회수·정찰·교란·항모를 각기 다른 실루엣으로 제작한다. 투명 비트맵 8종을 하나의 아틀라스로 공유해 편성, 선택 요약, 확인, 출항 시연, 선택적 실험실의 시각 언어를 맞춘다.

격납고는 실제 배경 삽화, 목표/수량/계산/버튼은 HTML이다. 장식 이미지에 글자를 굽지 않는다. 이미지 로딩이 실패해도 이름·역할·수량·검토 흐름을 유지한다. 원본 PNG와 프롬프트, 해시, 최적화된 WebP를 저장한다. 새 라이브러리는 설치하지 않는다.

## 모션 위계

| 사건 | 피드백 | 제약 |
|---|---|---|
| 수량 편집 | 260ms 함선 상승/복귀, 선택 테두리·체크 | 입력 노드를 교체하지 않아 포커스/캐럿 유지 |
| 격납고 | 9초 주기의 아주 약한 도킹 조명 | 낮은 대비의 장식만 움직임 |
| 확인 진입 | 400ms 등장, 500ms 항로 연결 | 자동 출항 없음 |
| 출항 시연 | 함선 등장, 별 이동, 엔진 맥동 | 로컬 장면만 전환, 게임 자산 불변 |
| 귀환·주둔·완료 | 방향·엔진·항로·상태 텍스트 전환 | 실제 전투 결과/보상 미생성 |

OS 모션 감소와 수동 일시정지에서는 정지한다. 페이지가 숨겨지면 CSS 애니메이션을 멈춘다. 명령 화면을 떠나면 해당 장식 DOM도 제거된다.

## 반응형·접근성

데스크톱은 함종 카드와 고정 계획 요약을 나란히 둔다. 모바일은 편성을 먼저 표시하고, 하단 내비게이션 위에 현재 척수·지휘와 계획 요약 바로가기를 둔다. 두 고정 영역의 실제 높이를 반영해 페이지 끝의 버튼이 가려지지 않게 한다. 작은 가로 화면에서는 요약 바를 일반 문서 흐름으로 돌린다.

수량 컨트롤은 최소 44px. 이름이 연결된 label, 숫자 min/max, 키보드 입력, 초점 복귀, 빈 편성 검증을 유지한다. 320px·390px·가로 화면의 200% 글자 확대와 실제 텍스트 대비를 검사한다. 색상 외에도 수량·체크·문구로 선택을 전달한다.
