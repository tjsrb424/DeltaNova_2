# 제품 UX 전략 — Minimal Galactic Command

## 결론

정보 밀도가 높은 OGame 계열의 재미를 유지하면서 평시 UI를 절제된 관제실로 만드는 방향을 **유지·발전**한다. 영웅 이미지나 이펙트를 먼저 늘리는 방식은 **삭제**한다. 기능과 콘텐츠를 삭제해 단순화하는 방식도 **반대**한다.

## 문제 진단 가설(실제 화면 확인 전)

1. 자원·건설·연구·행성·알림을 동등한 시각적 크기로 배치하면 행동 우선순위가 사라진다.
2. 패널마다 테두리·글로우·그라데이션이 제각각이면 완성도가 아닌 소음으로 인식된다.
3. 중앙 행성이 게임 상태와 무관한 정적 배경이면 공간을 많이 차지하는 장식이 된다.
4. 위협 경보가 일반 알림과 동일한 계층이면 대응 판단 속도가 늦어진다.
5. 고정 기능 수가 많은 화면을 단순히 숨기면 고급 유저의 정보 탐색 비용이 커진다.

## 핵심 UX 명제

- **기능 수가 아니라 동시 노출량을 제한한다.**
- **정보, 행동, 피드백은 분명히 다르게 보인다.**
- **의미 없는 반짝임을 없애고 상태 변화에만 모션을 쓴다.**
- **평시 화면과 전투 경계 화면이 동일한 기본 컴포넌트를 공유한다.**
- **주요 의사결정은 가능한 한 1~3회 행동 내 접근 가능하게 한다.** (가설 목표; 실제 테스트로 보정)

## 사용자 역할 / 주요 과제

| 유형 | 반복 목표 | 메인에서 즉시 보여야 하는 것 | 두 번째 단계로 미뤄도 되는 것 |
|---|---|---|---|
| 공격형 | 정찰→타깃 평가→출격→귀환 | 함대 현황, 출격 가능 여부, 위협, 최근 정보 | 상세 전투 로그 및 전투 수식 |
| 방어형 | 위험 인지→대응/회피→복구 | 도착 이벤트, 명확한 도착 시간, 방어/회피 진입 | 세부 방어 편성 공식 |
| 농장형 | 생산/투자→회수→성장 | 보유 자원, 건설·연구 진행, 다음 생산 목표 | 장기 생산 히스토리 |
| 외교·동맹형 | 협력 요청→세력 판단→의사결정 | 동맹 메시지/중요 이벤트 | 세부 외교 대시보드 |

## 시각적 레퍼런스의 역할 구분

- **Linear/Geist:** 정돈된 레이아웃, 컴포넌트 일관성, typography·spacing·navigation.
- **Destiny 2 등 SF 게임:** 중앙 행성의 스케일, 빛, 공간감, 위기 연출의 분위기만 참고.
- **Stellaris/OGame 계열:** 자원, 정치, 다중 행성, 함대 관리라는 정보 구조 참고. 복잡한 HUD를 그대로 모방하지 않음.

이 레퍼런스는 시각적/경험적 분석 자료일 뿐, 기존 상품의 브랜드나 고유 UI를 직접 복제할 근거가 아니다.

## 정보 계층

- **Tier 0 / 안전:** 공격 접근, 긴급 함대 판단, 치명적 오류, 잠금·취소 불가능한 결과.
- **Tier 1 / 행동:** 지금 착수할 수 있는 건설, 연구, 함대 명령, 진행중인 작업.
- **Tier 2 / 자산:** 자원·생산·제국 상태, 보유 행성, 동맹 관계.
- **Tier 3 / 탐색:** 역사·세부 통계·인벤토리·세부 로그·설정.

평시에는 Tier 1 + 요약된 Tier 2를 우선 제공. Tier 0가 발생하면 기존 구조 위에 빠르게 진입하여 주의를 이동. Tier 3는 온디맨드로 연다.

## 좋은 UX의 세 가지 실험

1. **5초 인지:** `내 자원은?`, `지금 진행 중인 건설은?`, `지금 위험한가?`를 설명 없이 알아보는가.
2. **실행 경로:** `건설 관리 열기`, `함대 상태 보기`, `경보 대응 옵션 확인`을 망설임 없이 수행하는가.
3. **복귀:** 세부 화면 닫고 이전 맥락으로 복귀했을 때, 작업 대상 행성과 상태가 유지되는가.

## 실제 반영 시 측정 후보

- 화면 첫 진입 시 주요 행동 발견 시간(초) / 과제 성공률(%).
- 유저별 메뉴 복귀 수, 경보 확인→대응 화면 진입 시간.
- 잘못된 함대 명령/취소 빈도, 경보 오독 비율, 가장 자주 열리는 패널.
- 1·7일 리텐션은 UI 개편의 장기 모니터링 후보이지 이 설계만으로 원인이라고 단정할 수 없음.

**절대 피할 것:** 기능을 감춰서 클릭 수만 줄이는 겉보기 간결화, 자원 실측값 대신 홍보성 수치, PvP 위협 알림을 화려한 이펙트 속에 숨기는 설계.
