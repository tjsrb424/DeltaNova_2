# AGENTS.md 병합용 추가 섹션(예시)

> 이 파일 자체를 프로젝트 루트의 `AGENTS.md`로 덮어쓰지 마세요. 현재 저장소의 기존 규칙을 먼저 읽고 충돌이 없는 위치에 이 섹션만 추가합니다. 또는 최초 Codex 프롬프트에서 별도로 참조합니다.

## DELTA NOVA — UI/UX Re-foundation

- UI/UX 업무에는 우선 `docs/uiux-refoundation/README.md`와 디자인 바이블을 읽습니다. 폴더 위치가 다르면 실제 경로를 보고 그 위치를 사용합니다.
- 기능적으로 검증되지 않은 디자인 추정값(자원·전투·이동·생산·연구 수치)을 앱 데이터로 취급하지 않습니다.
- 실제 코드 실사 및 UI 감사 → 토큰/정보구조 정리 → 분리된 대표 화면 시연 → 검증 → 사용자 승인 후 통합 순서를 지킵니다.
- UI 목적: **정보를 정돈하고 기능 발견성을 높이며, 평시에는 절제하고 위기에는 강한 피드백**.
- 중앙 행성은 제국 성장과 시각적으로 연결하되, 연결 데이터/임계값은 확인 후 정의합니다.
- 기존 경제/PvP/함대/정찰/동맹/네트워크/저장소/과금 로직을 승인 없이 수정하지 않습니다.
- 모든 작업은 `Idle / Incoming Threat / Completed / Loading / Empty / Error / Mobile / Reduced Motion`을 고려합니다.
- 새 라이브러리 도입 전에 현재 스택/성능/번들 영향 확인, 임의 의존성 추가 금지.
- 배포/상태 영속 변경/강제 reset/force push 금지. Git의 기존 사용자 수정 보존.
- 보고 시 변경 범위·테스트 결과·스크린샷·남은 위험·승인 요청을 구분하고 마지막에 반드시 `이렇게 테스트하세요`를 포함합니다.
