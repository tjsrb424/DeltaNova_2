# 델타 노바 시즌·은하 경쟁·분야별 랭킹 방향 v0.1

2026-10-14. 사용자가 제시한 시즌제, 무작위 행성 정착, 주변 탐색과 장악, 소규모 전쟁에서 대규모 길드전으로 확장되는 흐름, 분야별 점수와 랭킹을 기록한다. 시즌 종료 시 초기화 범위는 같은 대화의 사용자 답변으로 확정했다. 이어 사용자가 시즌 기간·종료 조건·분야별 점수의 추천안 작성을 위임하여 아래 운영 기본안을 추가했다. 수치는 첫 기획 추천값이며 실제 플레이·경제 시뮬레이션으로 검증된 최종 밸런스는 아니다. 시즌·은하 배치·PvP·길드전·랭킹은 현재 구현된 기능이 아니다.

## 사용자 확정 방향

- 델타 노바는 시즌제로 운영한다. 생산·건설·연구·함대 운용은 한 시즌 안에서 지속되고, 시즌 간 경쟁 자산은 초기화한다.
- 시즌 시작 시 은하의 무작위 행성에 정착한다. 주변 환경과 세력을 파악하고 영향력을 넓히는 것이 첫 전략 과제다.
- 가까운 세력 사이에서 소규모 전쟁이 자주 발생하고, 이후 길드 형성과 연합으로 대규모 길드전까지 번질 수 있다.
- 자원·전투 규모·방어 규모 등 분야마다 점수와 랭킹을 제공한다. 아래 세부 산식과 추가 분야는 사용자가 작성을 위임한 추천 기본안이다.
- 시즌이 끝나면 행성·자원·함대·연구·영토를 초기화하고, 기록·칭호·외형은 유지한다.

핵심 경험은 **새로운 입지에서 정착 → 주변 탐색과 성장 → 국지전과 영향권 경쟁 → 길드 형성과 협력 → 대규모 전쟁과 시즌 기록**이다. 이는 목표로 하는 플레이 흐름이며 정해진 날짜에 길드 가입이나 전쟁을 강제하는 단계표가 아니다.

## 시즌 기간과 종료 조건 — 추천 기본안

**정규 시즌은 12주(84일), 종료 후 휴식·기록 열람 기간은 1주(7일)**로 추천한다. 시작과 종료는 일요일 21:00 KST(12:00 UTC)로 맞춘다. 실제 첫 시즌의 시작 날짜는 운영 준비 뒤 공지하며 오늘을 시작일로 잡는 것은 아니다. 서버 판정은 UTC 시각을 저장하고 화면은 사용자 시간대로 표시한다.

기간 후보는 8주·12주·16주다. 8주는 초기화를 자주 경험하지만 성장과 길드전의 축적 시간이 짧고, 16주는 큰 전쟁을 오래 이어갈 수 있지만 선두 격차와 반복 운영이 길어질 수 있다. 12주는 정착·확장·전쟁의 시간을 나눠 검증하기 위한 중간안이다. 이 비교는 델타 노바의 의도에 따른 설계 판단이며 현재 플레이 데이터에 근거한 기간 최적화 결과는 아니다.

| 경험의 목표 구간 | 기대하는 변화 |
|---|---|
| 1~2주 | 본성 성장, 주변 탐색, 첫 교전과 이웃 관계 형성 |
| 3~8주 | 식민지·수송·전진 배치, 반복 국지전과 길드 협력 확대 |
| 9~12주 | 영향권 유지·탈환, 연합과 대규모 길드전, 분야별 순위 경쟁 |

이는 경제와 지도 밀도를 조정할 때 확인할 목표다. 길드 창설·가입·전쟁·개척을 해당 주차까지 잠그거나, 후반에 강제로 공격을 요구하지 않는다.

- 시작 시각을 `S`, 종료 시각을 `E = S + 84일`로 고정한다. 한 길드의 점유율·총점·승리 횟수가 높아져도 조기 종료하지 않는다. 패권을 빼앗을 남은 시간도 시즌 전략의 일부다.
- 종료 조건은 공지한 `E`의 도달이다. 전멸·모든 행성 점령·특정 보스 처치는 종료 조건으로 사용하지 않는다. 운영 장애 대응은 별도 운영 정책으로 남기고, 정상 경쟁의 승패에 따라 기간을 바꾸지 않는다.
- 개인 종합 순위는 종합 성장 점수로, 길드의 시즌 패권 순위는 누적 영향권 점수로 정한다. 각 분야의 1위와 상위 기록도 별도로 보존해 한 종류의 우승만 성취로 취급하지 않는다.
- `E` 이후 24시간은 최종 정산과 결과 확정 구간으로 두고, 경쟁 상태는 동결한다. 기록·칭호 지급은 확정 결과를 기준으로 한 번 처리한다. 다음 정규 시즌은 `E + 7일`에 새로운 은하와 초기 자산으로 시작하는 안이다.
- 시즌 도중 점수 가중치나 거점 가치를 바꾸지 않는다. 수정한 점수 규칙과 기간은 다음 시즌에 적용하고 기록에 해당 규칙 버전을 남긴다.

## 시즌 종료와 다음 출발

| 구분 | 시즌 전환 방향 |
|---|---|
| 본성·식민지·시설·자원·주둔/이동 함대·방어시설·연구·영토 | 새 시즌의 공통 시작 조건으로 초기화한다. 이전 시즌의 경제와 전력을 이월하지 않는다. |
| 시즌별 개인/길드 순위·전투 및 성장 기록 | 종료된 시즌의 기록으로 보존한다. 새 시즌 점수에 합산하지 않는다. |
| 획득한 칭호·외형 | 계정에 보존한다. 유지되는 외형과 기록이 초기화된 전력이나 생산 능력을 대신하지 않는다. |
| 새 시즌의 시작 행성 | 새 은하의 배치 규칙에 따라 무작위로 정착한다. 이전 영토의 소유권은 이어지지 않는다. |

종료 정산은 다음 순서를 추천한다.

1. 서버 수신 시각이 `E` 이상인 신규 경쟁 명령을 거절한다. `E` 전에 접수했더라도 사건 발생 시각이 `E`보다 늦으면 그 완료·교전·회수의 결과는 최종 점수에 넣지 않는다.
2. 사건 시각이 `E` 이하인 생산·작업 완료·도착·전투·파괴·영토 변화는 정해진 사건 순서로 모두 처리한 뒤 최종 상태를 만든다. 처리 서버가 늦게 실행됐다는 이유로 마감 이전 사건을 누락하지 않는다. 같은 시각의 사건 순서는 상세 전투·이동 설계에서 고정한다.
3. 살아 있는 이동·증원·귀환 함대도 보유 규모에 한 번 포함한다. 종료 전에 실제 파괴된 함대는 제외한다. 도착이 `E` 뒤인 전투를 앞당겨 가상 정산하지 않는다. 전투가 마감 이전에 완료됐다면 귀환이 마감 뒤여도 해당 전투 성과는 인정한다.
4. 미완료 건설·연구·조선은 완성 자산으로 세지 않는다. 미도착 약탈 화물은 회수 완료 기록으로, 미사용 지원 화물은 지원 성과로 세지 않는다. 약탈 자원은 도착 여부와 무관하게 자원·경제의 생산 점수에 더하지 않는다. 작업과 출격 화면에는 마감 이후 완료 예정임을 안내한다.
5. 최종 상태·사건·분야별 점수·소속을 보존하고, 24시간 정산 구간 뒤 결과를 확정한다. 재실행과 재전송은 같은 최종 결과와 같은 지급 영수증을 사용한다.

시즌 초기화는 향후 운영 규칙이다. 현재 로컬 개발 저장을 삭제하거나 초기화하는 작업을 뜻하지 않는다. 기존 저장의 보존·이전 계약은 유지한다.

## 정착과 주변 경쟁 — 세부 추천

무작위 배치는 매 시즌 다른 이웃과 항로를 만나게 하되, 시작 생산 능력과 즉시 생존 가능성의 차이는 제한하는 안을 추천한다. 임의 좌표를 먼저 정하고 불리한 출발을 그대로 방치하는 대신, 시작 가능한 후보 행성의 조건을 검증한 뒤 추첨한다. 후보 조건·인구 밀도·신규 참가자 보호·늦은 참가자의 배치 규칙은 미정이다.

초반에는 가까운 행성과 NPC 거점, 자원 입지, 이동 거리와 주변 세력의 존재를 발견한다. 탐색은 위치와 존재를, 정찰은 관측 시점의 자원·함대·방어 정보를 제공한다. 공개 랭킹이 이 정보전 전체를 대신하지 않게 한다.

국지전의 동기는 주변 자원, 수송 경로, 전진 배치와 영향권에서 만든다. 사용자가 말한 주변 장악의 구체적인 대상은 미정이다. 일반 습격이 상대 본성을 영구 탈취하는 것으로 해석하지 않으며, [식민지 방향](DELTA_NOVA_COLONIES_V0.1.md)의 성장·복구 경계를 따른다. 전략 거점이나 항로를 경쟁 대상으로 삼는 안은 후속 검토 대상이다.

길드의 필요는 반복되는 이웃 관계, 공동 방어, 수송과 협공에서 자연스럽게 커지게 한다. 초반 길드 창설을 금지하거나 특정 날짜부터 강제로 대규모 전쟁을 시작하는 규칙은 승인되지 않았다. 길드가 없어도 생산·연구·개척·정찰·공격·방어의 기본 순환을 진행할 수 있어야 한다.

## 점수와 랭킹 구성 — 세부 추천

종합 점수만 두는 안, 분야별 순위만 두는 안, 두 종류를 함께 두는 안 중 **종합 성장 + 분야별 랭킹**을 추천한다. 보유 규모와 누적 성과는 합쳐서 하나의 만능 점수를 만들지 않는다. 각 분야의 개인 순위와 아래 별도의 길드 순위를 제공한다.

### 공통 평가 단위

`V(자원) = 합금 + 결정 + 연료`, `P(자원) = V / 10`으로 둔다. 첫 추천안은 세 자원의 가중치가 모두 1이고 10자원당 1점이다. 이는 점수 환산 단위이며 교역 환율이나 자원의 실제 전략 가치를 뜻하지 않는다. 거래 시세에 따라 점수가 흔들리는 방식은 사용하지 않는다.

시설·함선·방어시설·연구는 시즌 시작에 공개한 **표준 비용표**로 평가한다. 생산 할인, 실제 구매 가격, 플레이어 거래 가격과 무관하게 같은 자산은 같은 규모 점수를 갖는다. 시설과 연구는 현재 레벨까지 완료된 단계의 표준 비용을 합산한다. 무료 초기 시설 단계의 평가 비용은 0으로 두고, 초기 함선은 해당 함종의 표준 가치로 규모에 포함한다. 이 조건은 모든 시작 참가자에게 동일하게 적용한다.

첫 시즌용 표준 비용 후보와 레벨별 누적 가치는 [건설·함대·연구 통합 기획](DELTA_NOVA_CONTENT_BALANCE_V0.1.md)과 [전체 레벨 곡선](balance/level-curves.json)을 따른다. 현재 시제품의 빠른 가격을 미래 시즌의 고정 가격으로 사용하지 않는다.

기본7종 시설의1단계는 초기 기반으로서 모든 행성에서 표준 성장 가치0으로 두는 안이다. 다른 행성에 유료로 설치했어도 같은 시설의 규모 점수는 같고 실제 설치 비용은 지불한다. 초기 지급이 아닌 시설은1단계부터 표준 비용을 포함한다.

합산 전에 개별 자산을 내림하지 않는다. 자산·생산의 기준량은 자원 단위 정수로 보관한다. 전투의 비율 배분과 보유 시간의 분수도 중간 단계에서 반올림하지 않고 산출 근거를 보존해 재계산한다. 본인의 표시 점수는 소수 첫째 자리까지 제공하되 순위는 표시 전에 보존한 원점수로 정한다. 보유 규모는 파괴·소유권 변화 때 내려가지만 누적 성과는 과거의 유효 사건으로 남는다.

### 개인 랭킹 기준

| 분야 | 추천 점수 기준 | 집계 성격과 제외 항목 |
|---|---|---|
| 종합 성장 | `G = F + H + B + R` | 현재 자산. `F`는 모든 현지 시설, `H`는 모든 보유 함선, `B`는 방어시설, `R`은 제국 공통 연구의 표준 비용 환산 점수다. 현금·생산량·전쟁 성과·영토 점수를 다시 더하지 않는다. |
| 자원·경제 | 시즌 시작 이후 실제 생산되어 저장에 반영된 자원의 `P` 누적 | 누적 성과. 초기 지급·선물·수송·약탈·잔해·보상·취소 환급은 생산이 아니다. 저장 포화로 버린 자원도 제외한다. 생산한 자원을 써도 기존 생산 점수는 유지한다. |
| 생산 능력 | 영구 시설·기술과 실제 전력 공급을 적용한 분당 생산률의 합 × `1,440 / 10` | 현재 산업의 24시간 생산 가능량 환산. 저장 포화와 접속 횟수는 반영하지 않으며 한시적 버프는 제외한다. 실제 누적 생산량과 별도 순위다. |
| 전투·함대 규모 | `H = Σ P(보유 함선의 표준 건조 비용)` | 현재 소유 규모. 정찰·수송·지원 함종도 포함한다. 손상·이동·증원 중인 생존 함선은 한 번 포함하고 완전 파괴·미완료 건조는 제외한다. 즉시 전투 가능한 전력의 수치를 뜻하지 않는다. |
| 방어 규모 | `B = Σ P(생존 방어시설의 표준 건설 비용)` | 현재 시설 규모. 주둔 함대는 `H`에만 들어간다. 전력 부족으로 비가동 중이어도 규모에는 포함하되 실제 방어 가능량과 구별한다. |
| 연구 | `R = Σ P(완료된 연구 단계의 표준 비용)` | 현재 기술. 제국 공통 연구를 식민지별로 복제해 계산하지 않는다. 진행 중 연구는 제외한다. |
| 개척 | 본성을 제외한 현재 소유 식민지당 100점 | 현재 확장 규모. 같은 행성을 포기·재개척해도 누적 횟수 점수를 주지 않는다. 식민지 시설은 이미 `F`에 반영한다. |
| 영향권 | 직접 소유한 전략 거점의 가치 × 유효 보유 시간 | 누적 성과. 아래 거점 규칙을 따르고 일반 본성·식민지는 영향권 거점으로 자동 계산하지 않는다. |
| 공격 성과 | 공격 측으로 얻은 유효 전투 점수의 누적 | 누적 성과. 아래 전투 산식·상대 규모 보정·반복 교전 규칙을 적용한다. 승리 횟수나 약탈량은 참고 기록이며 이 점수에 더하지 않는다. |
| 방어 성과 | 방어 측으로 얻은 유효 전투 점수의 누적 | 누적 성과. 수비자가 실제 전력 손실을 감수하고 낸 결과를 평가한다. 공격을 받았다는 사실만으로 점수를 주지 않는다. |
| 병참·지원 | 동료의 유효 전투 손실 복구·유효 작전 보급에 실제 사용된 지원 자원의 `P` 누적 | 누적 성과. 도착만 한 선물·창고 보관·자기 수송·반송·일반 확장 투자는 제외한다. 같은 지원 자원은 한 번만 인정하고 복구량은 해당 손실 비용, 보급량은 해당 작전 소비량을 넘지 못한다. |

자원·경제의 주 순위는 누적 실제 생산량으로 선택했다. 비축량을 주 점수로 삼으면 지출을 미루는 것이 유리하고 정확한 약탈 목표를 공개하기 쉽다. 생산 능력만으로 평가하면 시즌 동안 운영한 산업의 결과가 남지 않는다. 두 순위를 나누면 산업의 누적 결과와 현재 능력을 모두 비교할 수 있다.

### 전투 성과 산식

한 전투에서 상대의 영구 손실 표준 점수를 `D`, 내 편의 영구 손실 표준 점수를 `L`로 두고, **전투 기본 성과는 `Q × max(0, D - 0.5 × L)`**로 추천한다. HP를 깎았다가 수리한 양, 회복·자동 재건으로 살아난 자산은 영구 손실에 포함하지 않는다. 예를 들어 상대 손실 1,000점·내 편 손실 400점·규모 보정 1이면 기본 성과는 800점이다.

`Q`는 전투 직전 참전 계정들의 종합 성장 합계를 양측 각각 구해 계산한다. `r = 상대측 성장 합계 / 내측 성장 합계`에서 `r < 0.25`이면 `Q = 0`, 그 외에는 `Q = min(1, r)`이다. 내측 합계가 0인 경우도 0점으로 처리한다. 작은 함대만 보내 자기 제국 규모를 감추는 방식으로 보정을 피하지 않는다. 자산을 잃은 결과가 아닌 전투 직전 상태를 사용한다. 이 보정은 점수 기준이며 공격 허용·신규 보호 규칙을 대신하지 않는다.

다수 참가자의 기본 성과는 영구 파괴된 적 자산에 가한 유효 피해 비중으로 나눈다. 실제 HP를 넘는 과잉 피해는 빼고, 각 적 자산의 점수는 참전자가 합쳐 한 번만 받는다. 참가자의 몫을 피해 대상 계정별로 다시 나누어 다음 반복 보정을 적용한다. 지휘자나 마지막 타격자에게 전체 성과를 중복 지급하지 않는다.

같은 두 계정 사이의 점수 대상 교전은 공격·방어 방향을 합쳐 최근 24시간에 첫 교전 100%, 두 번째 25%, 세 번째부터 0%로 반영한다. 한 전투의 여러 함선 파괴는 교전 한 번으로 센다. 여러 참가자가 서로 다른 상대와 싸웠다면 해당 계정 쌍의 몫만 각각 보정한다. 전쟁 행동과 자원·영토 결과는 정상 규칙대로 처리하고 성과 점수에만 이 감쇠를 적용한다.

연습·NPC 전투, 같은 길드의 내전, 같은 길드에서 나온 지 7일 이내인 상대와의 전투, 자기 계정 간 전투는 경쟁 성과에서 제외한다. 지원의 유효 전투·작전도 이 제외 기준을 따른다. 공격 성공·방어 성공·약탈·철수·거점 점령은 별도 전투 기록으로 보존한다. 점수가 0이라고 실제 승리나 손실을 없던 사건으로 만들지는 않는다.

### 영향권과 길드 랭킹

영향권은 임시로 많은 거점을 찍는 행동보다 유지·방어·탈환을 평가한다. 전략 거점의 첫 점수표는 일반 중계 거점 10점/시간, 주요 병참 거점 30점/시간, 핵심 도약문 60점/시간으로 추천한다. 거점 종류와 실제 지도 배치는 후속 세계 설계의 대상이고, 이 표 자체가 현재 점령 기능의 구현을 뜻하지 않는다.

거점을 **연속 6시간 보유한 뒤부터** 해당 가치로 점수를 적립한다. 첫 6시간은 소급 지급하지 않는다. 이후 유효 보유 시간은 분 단위로 환산해 마감과 탈환 시각까지 계산한다. 소유권이 바뀌면 새 소유자는 다시 6시간을 확보해야 하고 이전 소유자의 누적 성과는 보존한다. 일일 수령 버튼이나 특정 시각의 마지막 소유자에게 하루치 전체 점수를 주지 않는다.

각 거점의 소유자는 개인 또는 길드 한 곳이다. 같은 보유 시간을 개인과 길드에 동시에 지급하지 않는다. 개인 거점을 길드에 넘기는 행위도 명시적인 소유권 이전으로 처리한다. 길드명 변경은 같은 길드 ID의 점수를 유지하고, 해산·신설·합병은 이전 길드의 누적 성과를 새 길드로 복사하지 않는다.

| 길드 분야 | 추천 집계 기준 |
|---|---|
| 종합 규모 | 가입 후 24시간이 지난 현재 구성원의 `G` 합계. 탈퇴자는 즉시 제외한다. 총원과 1인당 규모도 비교 정보로 제공한다. |
| 함대·방어 규모 | 위와 같은 집계 대상 구성원의 `H`, `B` 합계를 각각 별도 순위로 제공한다. |
| 영향권·시즌 패권 | 길드가 직접 소유한 전략 거점의 누적 유효 보유 점수. 마지막 날의 소유 개수만으로 결정하지 않는다. |
| 전쟁 성과 | 해당 길드에 귀속된 유효 개인 공격·방어 성과의 합계. |
| 병참·지원 | 해당 길드에 귀속된 개인 유효 지원 점수의 합계. |

원정·증원·지원 사건의 길드 소속은 관련 출격 또는 지원 명령을 서버가 접수한 시점으로 고정한다. 출격 명령이 없는 본인 거점의 주둔 방어는 해당 전투 직전 소속을 사용한다. 각 소속 고정 시점에 가입 후 24시간이 지난 참가자의 사건만 길드 성과로 인정한다. 이후 가입·탈퇴로 지난 성과를 옮기지 않는다. 귀속된 몫은 당시 길드에 남고 개인 기록도 유지한다. 현재 규모와 누적 성과의 소속 기준을 구별한다.

### 계산과 동률 예시

- 시즌 후보 카탈로그의 케스트럴은 합금1,800·결정1,000·연료400이다. 10척은 `H = 3,200점`, 3척을 잃으면2,240점이고 앞서 쌓은 공격 성과는 유지한다.
- 누적 실제 생산이 합금10,000·결정6,000·연료4,000이면 자원·경제는 2,000점이다. 그중 5,000자원을 연구나 수송에 써도 생산 점수는 변하지 않는다.
- 새 시즌 기본 생산인 시간당 합금120·결정90·연료70을 유지한다면 생산 능력 점수는 `280 × 24 / 10 = 672점`이다. 종합 성장 점수에 이 값을 더하지 않는다.
- 일반 중계 거점을 연속 9시간 지키면 최초 6시간을 제외한 3시간 × 10으로 30점이다. 마지막 1시간에 빼앗은 길드는 0점이며 이전 소유자의 30점은 사라지지 않는다.
- 원점수가 같으면 공동 순위로 둔다. 예를 들어 1위·공동 2위·공동 2위 다음은 4위다. 가입 시각·접속 횟수·계정 ID로 우승을 가르지 않으며 해당 순위 칭호를 각자 받는다.

## 랭킹과 정보전의 경계 — 세부 추천

공개 랭킹은 매 정시의 스냅샷을 **1시간 지연**해 제공한다. 표기에는 집계 시각을 명시하고 공개 점수는 유효숫자 두 자리에서 아래 방향으로 표시한다. 순위와 동률은 반올림한 표시값이 아닌 원점수로 계산한다. 예를 들어 12,345점은 공개 화면에서 약 12,000점으로 보이며, 본인의 상세 화면은 현재 원점수를 제공한다. 종료 후에는 같은 공개 정밀도로 최종 순위를 표시하고, 본인에게 최종 산출 내역을 제공한다.

상대의 자원 종류별 비축량·함종별 수량·주둔 위치·행성별 방어 구성·개별 전투 상대 목록은 랭킹 API로 보내지 않는다. 점수 지연과 표시 정밀도는 즉시 재고 역산을 줄이기 위한 기준이며 모든 추론을 차단한다고 보장하지 않는다. 실제 공개 API와 카탈로그를 함께 사용한 정보 노출 검증은 세계·정찰 구현 단계에서 수행한다.

점수는 서버가 확정한 자산과 시즌별 사건으로 계산한다. 단순 수송은 누적 생산을 늘리지 않고, 내부 이동은 함대를 복제하지 않으며, 취소·환급·반복 요청은 같은 성과를 중복 지급하지 않는다. 지원 자원은 원 지원 사건과 실제 소비 사건을 연결해 한 번만 인정한다. 정산 전후의 상태·사건 ID·소속·규칙 버전으로 점수 산출을 재현할 수 있어야 한다.

시즌 종료 기록은 분야별 순위를 보존하고, 수상 칭호는 여러 역할의 성취를 드러내는 방향을 추천한다. 시즌 간 수치 비교는 시즌 길이·참가자 규모·규칙 차이를 함께 표시해야 한다. 이전 시즌 점수가 새 시즌 순위를 결정하지 않는다.

## 구현 상태와 개발 연결

현재는 본성 한 개의 현지 생산·시설·조선·방어 재고·제국 공통 연구와 개인/공동 작전을 제공한다. 저장 모델에 운영 시즌, 무작위 은하 배치, 실제 길드 소속과 공개 랭킹은 없다. 동맹 메뉴의 개발용 역할 보드는 대규모 길드전 구현이 아니다. [README](../../README.md)와 [행성 기지 보고서](../validation/PLANET_BASE_REPORT.md)의 구현 경계를 따른다.

개발 순서 제안은 기존 첫 성계 순환을 유지한다. 거리·이동·정찰·공격·방어·귀환을 연결하고 식민지·수송을 검증한 뒤, 시즌 세계와 실제 참가자 간 경쟁으로 확장한다. 다음 성계·세계 상세 설계에서는 영구 계정 기록과 시즌 자산의 분리, 시즌별 명령·사건·점수의 귀속을 요구사항에 포함한다. 아직 구현 순서나 데이터 인터페이스가 확정된 계획은 아니다.

## 후속 검증과 남은 상세 설계

시즌 기간·정상 종료 조건·분야별 기본 산식·공개 범위·마감 처리는 위 추천안으로 기획에 반영했다. 다음에는 대표 성장 곡선과 전쟁·복구 비용으로 84일 동안 각 역할이 언제 경쟁 가능한지 검증한다. 자원 가중치 1:1:1, 손실 공제 0.5, 규모 보정 0.25, 반복 교전 100%/25%/0%, 거점 6시간과 10/30/60점은 그 검증에서 조정할 수 있는 첫 값이다.

실제 첫 시즌 날짜, 무작위 시작 후보와 참가자 보호, 점령 가능한 거점의 수·배치·탈환 규칙, 동일 시각 사건 순서, 지원 자원의 소비 추적, 계정 간 관계 판정과 점수 재산출 인터페이스는 후속 상세 설계로 남긴다. 이 문서는 해당 시스템의 구현 계획이나 운영 준비 완료를 뜻하지 않는다.
