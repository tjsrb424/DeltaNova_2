# 함대 운용 중심 UI/UX 검수

2026-10-16 · `codex/uiux-refoundation` · 서버 미연결 데모 · 로컬 미커밋 변경

사용자가 정한 방향은 **목표를 고르고 함대를 보내 싸우는 간단한 행동 안에 전략을 담는 것**이다. 이번 UI 작업에 필요한 추가 결정은 없으며, [설계 방향](./STRATEGY_DIRECTION.md)에 맞춰 기존 개인·동맹 작전 화면을 재구성했다. 이전 작전/동맹 검수 문서는 당시 구현의 이력이다. 현재 진입 흐름은 이 문서를 우선한다.

## 반영한 흐름

- **출격 목표 → 함대 편성 → 명령 확인**을 개인·동맹·은하·방어의 공통 흐름으로 사용한다. 이야기형 작전을 고른 뒤 편성 연습을 해야 하는 단계를 없앴다. 편성 실험실은 선택 메뉴로 남겼다.
- 공격·정찰·이동·증원에 맞는 목적지를 표시한다. 은하에서 내 행성은 이동, 동맹 행성은 증원, 외부 거점은 공격/정찰 준비로 진입한다. 미라의 동맹 소속은 지도와 목록에서도 일관되게 표시한다.
- 함대 편성에서는 도착 시각·연료·현지 잔류 함대를 먼저 보여준다. 균형·화력·기동 편성을 시작점으로 사용할 수 있고, 8종 함선을 직접 조정할 수 있다. 전력·속도·화물의 비교값은 편성에 따라 바뀐다.
- 출발 시점은 직접 선택한다. 명령 확인 전에는 출발하지 않는다. 확인 화면에서 목적지·함선 조합·출발/도착 시각·연료·남길 함대를 다시 볼 수 있다.
- 동맹은 **공동 목표와 동료들의 도착 시각**으로 설명한다. 역할 예약과 선행 준비 임무를 없앴다. 같은 편성 화면으로 합류하며, 도착 시각 맞추기는 명시적인 선택이다. 느린 편성으로 예정 시각에 도착할 수 없으면 더 빠른 편성이 필요하다고 안내한다.
- 함대 목록의 출항·도착·귀환은 사용자가 다음 장면을 눌러 보는 로컬 시연이다. 이동·증원은 도착 후 주둔하고 명시적으로 귀환을 선택한다. 활동 중인 시연 함선은 출발지 가용 수에서 제외되며 귀환 완료 때 돌아온다.
- 방어에서는 남길 함대, 다른 내 행성으로 이동, 동료와 대응 조율을 비교한다. 기존 실제 스냅샷과 시연 가용 함선 수는 이름을 구분한다.

## 직접 검수하며 고친 부분

- 390px 화면에서 핵심 시각과 명령 확인 버튼이 긴 함종 목록 아래에 묻히지 않도록 요약을 먼저 배치했다. 상세 조합은 접어서 표시하며, 편성/시점 조정과 확인 영역 사이에 이동 버튼을 제공한다.
- 중복 제목과 긴 단위를 줄였다. 목적지 카드의 거리 숫자는 기준 이동 시간으로 바꾸고, 편성에 따라 바뀐다는 설명을 붙였다.
- 수량 변경 때 입력 노드와 초점·스크롤을 유지한다. 검토 제목으로 초점을 옮기고 수정/뒤로 가기 동선을 복원한다.
- 별도 읽기 전용 검토에서 발견한 초기화 후 URL/목적지 불일치, 출항 뒤 Back으로 다른 편성의 확인이 생성되는 문제, 맞추기 실패를 성공으로 안내하는 문제를 회귀 테스트와 함께 수정했다. URL만으로 새 확인안을 만들지 않는다.
- 글자 200% 확대의 320px 화면에서 제목과 시각 카드가 가로로 넘치는 문제를 수정했다. 제목은 줄을 바꾸고 시각 카드는 필요한 경우 한 열로 내려간다.
- 함선이 없는 행성, 모두 시연 중인 상태, 직접 선택한 수량이 0인 상태의 안내를 구분했다.

## 검증 근거

- `npm test -- --maxWorkers=2`: **30개 파일, 315개 테스트 통과**.
- `npm run build`, `npm run verify:build`, `git diff --check`: 통과.
- `node tools/verify-uiux-polish.mjs`: **35개 브라우저 통합 검사, 기존 행성 상태 15개 레이아웃 통과**. 새 출격/편성/확인/동맹은 1440×900, 839×1065, 390×844, 320×568, 844×390에서 확인했다. 320·390·가로 화면의 글자 200% 확대도 검사했다.
- Chrome 반응형 화면에서 공유 HTTPS의 출격·동맹·시각 조정·확인을 직접 열고 확인했다. 실제 아이폰 기기 검수를 수행했다는 뜻은 아니다.
- API 요청·비GET 요청·저장소 접근·브라우저 실행 오류 0건. 게임 API 4318 미실행, 게임 DB 미생성, `src/` 변경 없음.
- 공유 주소의 HTML/명령 모델/화면/CSS/컨트롤러/은하/워크스페이스 파일 7개가 현재 로컬 파일과 일치했다. `/api/guild`는 404, 공유 정적 페이지는 `connect-src 'none'`을 유지한다.
- [검수 결과와 화면](../qa/2026-10-16-strategy/README.md). 모델/컨트롤러의 별도 재검토에서 지적 사항 3건이 해결되었음을 확인했다.

## 데모의 경계

전투·이동·증원·도착 시각·편성 지수는 디자인을 검토하기 위한 예시다. 실제 전투 계산·승률·손실·보상·게임 시간·동료 통신을 구현하거나 변경하지 않았다. 현지 주둔은 시연 목록에만 남으며 목적지 재고로 옮기거나 재출항하지 않는다. 상단 스냅샷 자원과 실제 함선 수는 유지한다. 홈의 기존 네온 항로 시연과 새 명령 목록은 각각의 표현 시연이다.

이 방향은 “플레이어가 무엇을 결정하는가”를 구체화한다. 함선 상성·이동/연료 수치·전투 규칙은 기존 운영 코드와 별개이며 이번에 확정한 게임 규칙으로 취급하지 않는다.
