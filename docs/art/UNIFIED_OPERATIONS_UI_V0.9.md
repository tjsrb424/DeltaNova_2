# 동맹·편성 연습 UI 통일 v0.9

2026-10-14 사용자 요청에 따라 기존 두 화면을 [행성 운영 UI](PLANET_MANAGEMENT_UX_V0.8.md)의 디자인과 통일했다. 주 작업자가 실제 렌더링과 조작을 직접 검수하고 부족한 배치를 수정했다. [직접 검수 기록](../qa/2026-10-14-unified-operations/REVIEW.md)에 최종 화면과 검증 근거가 있다.

- 공통 메뉴는 `OperationsNav`를 사용한다. 대시보드·건설·함대·연구·개인 작전·동맹·보고서·편성 연습의 이름과 위치를 유지한다. 좁은 화면과 창 크기 변경 시 현재 카테고리를 가로 메뉴 안에 표시한다.
- 흑연색 메뉴, 밝은 세라믹 본문, 청록색 선택·실행, 얇은 경계, 간결한 헤더와 동일한 버튼 규칙을 사용한다. 선택은 색상 외에 경계·체크·`aria-pressed/current`로도 표시한다.
- 동맹은 간결한 공동 목표·역할 완료 수, 참가자 상태, 역할 카드, 선택한 역할의 조건·편성·수행, 기여 보고서·공헌 순서로 읽는다. 큰 도약문 장식과 개발 참가자 설정은 핵심 행동보다 먼저 공간을 소비하지 않는다.
- 역할 선택은 해당 브리핑으로 이동한다. 새 수행 결과만 보고서로 포커스를 옮기며 초기 서버 읽기와 과거 보고서를 가진 역할 선택은 브리핑을 가로채지 않는다. 미확정 명령의 재전송·재연결을 유지한다.
- 편성 연습은 로컬 연습임을 표시한다. 목표·함대·지원·항로·출격 흐름을 사용한다. 본문 높이에 맞춘 브리핑에서 지원·항로는 스크롤하고 선택한 목표·준비 상태·실행은 아래 영역에서 확인한다. 매우 짧은 공간에서는 일반 흐름으로 전환한다.
- 연습의 연구 데이터·모듈은 서버 자원과 분리해서 표시한다. 저장된 연습 작전이 있어도 동맹은 실제 공동 작전 화면을 표시하고, 연습으로 돌아가면 해당 보고서를 이어서 확인한다.
- 규칙·비용·전투·보상·서버 인증·저장 형식은 변경하지 않았다. 연습의 저장 충돌·기록 복구, 작전 종료 전 연습 내 이동 잠금, 공동 작전의 예약·수행·재전송 보호를 유지한다.

새 함선 비트맵이나 전투 애니메이션을 만들지 않았다. 기존 함선 도형·지도·도약문 표현을 읽기 쉬운 색상과 크기로 사용한다. 해당 아트 보강은 별도 후속 작업이다.
