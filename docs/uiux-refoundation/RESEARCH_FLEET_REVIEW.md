# 연구·함대와 메뉴 전환 후속 검수

2026-10-15 · `codex/uiux-refoundation` · 독립 데모만 수정 · 로컬 미커밋

## 직접 확인한 문제와 반영

- 메뉴 전환: 중앙 화면 방식은 유지했다. 주요 화면의 제목 높이를 통일하고 140ms의 불투명도 변화만 사용해 수직 이동을 없앴다. 빠른 연속 전환 시 이전 애니메이션을 취소한다. 선택 중인 메뉴를 다시 누르면 새 이력 없이 화면 처음과 제목으로 복귀한다. 브라우저 뒤로·앞으로 가기는 기존 읽던 위치 복원을 유지한다.
- 연구: 같은 내용을 다시 여는 요약 버튼과 중복 안내를 줄였다. 공통 연구의 진행·남은 시간·연구 행성과 현지 연구소의 다음 수준·지원 범위·예시 비용을 나누었다. 연구소 비교 링크는 건설의 연구소를 직접 선택한다. 진행 중인 공통 연구는 베스퍼를 선택해도 유지하며 현지 투자 값은 베스퍼 기준이다.
- 함대: 보유·출격 가능·조선소 수준을 간결하게 묶었다. 선택 행성의 출항과 적 접근을 서로 다른 색과 명칭으로 표시하며 남은 시간을 기존 단일 시연 시계에 연결했다. 종료 시 출항은 ‘외부 항로 이탈’, 접근은 ‘외곽 대기’로 바뀐다. 다른 행성의 경로를 현지 경로로 표시하지 않는다.
- 함대의 출항 시연 버튼은 기존 로컬 시연 전환을 재사용한다. 보유량·재고는 바뀌지 않으며 다시 누르면 시연 경로만 지운다. 조선소의 다음 수준과 비용, 편성 연습·개인 작전으로 이어지는 이동을 가까이 배치했다.
- 모바일: 연구소 비용과 비교 버튼을 위로 당겼다. 390×844에서 연구소 비교 버튼 전체가 하단 메뉴 위에 보인다. 844×390 가로 화면은 연구·함대의 주요 카드 두 개를 나란히 배치한다. 세로 화면은 한 열로 읽는다.
- 반복 검수에서 이전 DOM 컨트롤러의 이벤트가 남지 않도록 데모 이벤트·타이머·관찰자 해제를 추가했다. 관련 포커스와 메뉴 재선택 회귀 테스트를 통과했다.

## 검증

- 전체 Vitest: **25개 파일, 228개 테스트 통과**.
- `npm run build`, `npm run verify:build`, `git diff --check` 통과.
- 정적 빌드만 제공한 `tools/verify-uiux-polish.mjs`: **24개 통합 검사·15개 상태별 레이아웃 통과**. 연구·함대의 200% 텍스트 확대, 대비, 가로 넘침, 제목 위치, 모바일 비교 버튼, 행성별 범위, 자산 불변, 경로 종료 문구까지 검사한다.
- 사용자에게 열려 있던 Chrome 데모 탭에서 화면을 직접 조작했다. 데스크톱 연구·함대 전환, 390×844 모바일의 연구 투자와 출항·적 접근 카드, 844×390 가로 연구 배치를 확인하고 기본 뷰포트로 복원했다. 기존 인앱 브라우저 세션에는 탭이 남아 있지 않아 같은 로컬 URL의 열린 탭을 사용했다.
- 독립 코드 리뷰와 별도 정적 Chromium 검사에서 320·390·769·800·1025px의 가로 넘침, 시설 링크, 행성별 항로, 로딩·오프라인 표시, 포커스를 확인했고 남은 수정 사항은 발견되지 않았다.
- 기존 행성 자전·구름·위성·외곽 항로·도착 효과·모션 감소 검사를 유지했다.

## 범위

게임 API·DB·운영 UI·게임 규칙은 변경하거나 연결하지 않았다. 브라우저 검사 중 API/비 GET 요청·Storage 접근·실행 오류는 0건이었다. 검수 후 포트 4318의 리스너 0개, `.delta-nova/guild.sqlite` 없음도 확인했다. 5180은 프런트엔드 정적 데모다.

연구·비용·함대와 항로는 예시다. 실제 연구·함대 명령은 비활성화되어 있다. 단일 출항 시연을 다른 행성에서 시작하면 이전 시연을 대체하는 기존 모델을 유지했다. 공통 연구의 고정 진행과 예시 시설 수준은 실제 게임 조건을 검증하는 데이터가 아니다.
