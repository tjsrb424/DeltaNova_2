# Delta Nova

안전한 기지에서 함대를 준비하고, 작전의 목표와 위험에 맞춰 편성한 뒤, 계속 진입하거나 귀환할 시점을 판단하는 우주 전략 게임.

## 현재 상태

2026-10-13에 새 프로젝트를 시작했다. 사용자가 승인한 방향은 **지속적으로 성장하는 기지와 함대 편성 중심의 작전 수행**이다. 기존 오게임형 설계의 규칙과 수치는 새 프로젝트의 제약으로 사용하지 않는다.

현재는 첫 플레이 가능한 구간의 설계를 검토하는 단계다. 게임 실행 파일이나 애플리케이션 코드는 아직 없다.

## 설계 문서

- [첫 프로토타입 설계](docs/superpowers/specs/2026-10-13-delta-nova-first-operation-design.md): 대표 작전, 함선 역할, 전투와 귀환, 성장 보상, 화면 흐름, 기술 경계, 검증 기준.

설계 문서의 **사용자 승인 사항**과 **검토할 상세 제안**을 구분한다. 상세 제안은 구현 결과나 검증을 마친 밸런스가 아니다.

## 작업 원칙

- 재미의 검증 단위는 편성 변경, 진입과 귀환 판단, 결과 이해다.
- 게임 규칙은 UI와 분리하고 같은 입력으로 결과를 재현할 수 있게 한다.
- 첫 구현은 로컬 단일 플레이 작전 하나에 집중한다. 서버, 계정, PvP, 결제, 앱 패키징은 별도 단계다.
- 개발 검증은 헤드리스로 수행한다. 창이나 미리보기는 현재 작업에 대한 명시적인 요청이 있을 때만 연다.
- 승인된 방향, 실험용 수치, 실제 검증 결과를 서로 구분해 기록한다.
