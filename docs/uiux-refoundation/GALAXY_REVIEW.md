# 은하·정찰 데모 디자인·모바일 검수

2026-10-15 · `codex/uiux-refoundation` · 로컬 미커밋 변경

## 구현과 화면 평가

기존 어두운 중앙 작업 화면에 은하·정찰을 구체화했다. 리라·오리온 2개 성역에 9개 고정 예시 대상을 두고, 지도·목록·선택 대상 상세를 연결했다. 데스크톱은 지도와 목록을 왼쪽, 상세를 오른쪽에 배치하며, 짧은 관측 보고서만 기존 상세 패널을 사용한다. 모바일은 지도 → 대상 선택 메뉴 → 상세 → 전체 목록 순서다.

행성 이름·영문 식별자·좌표로 검색할 수 있다. 전체/내 행성/소속 미확인 필터와 현재 행성 찾기를 제공한다. 선택 상태는 지도·목록·모바일 선택 메뉴에 함께 반영된다. 관측 대상 선택은 상단 보유 행성이나 자원을 변경하지 않는다. 내 행성의 관제로 이동 버튼을 명시적으로 눌러야 보유 행성이 바뀐다.

정찰 시연은 1.4초 뒤 메모리 안에 예시 보고서를 생성한다. 사전 관측 자료와 정찰 시연 결과의 출처를 구분하고 자원·시설은 정성적 신호로, 함대는 미확인으로 표시한다. 정찰 중 다른 대상을 선택해도 원래 대상에 결과가 남는다. 완료 시 화면·패널을 자동 전환하지 않는다. 실제 정찰 명령은 비활성 상태다.

직접 화면을 보며 다음 문제를 수정했다.

- 839px·320px에서 겹치던 지도 클릭 영역: 중간 화면의 표식 크기와 예시 배치를 조정했다. 최소 44px 클릭 영역을 확보하며 확대 글자에서는 지도 높이가 함께 늘어난다.
- 작은 화면에서 여러 줄로 잘리던 분류 버튼: 필터를 전체 너비로 배치하고 결과 수·현재 행성 찾기를 다음 행에 정리했다.
- 320px에서 제목보다 먼저 왼쪽에 놓이던 관제 복귀 버튼: 공통 제목 순서를 유지하도록 수정했다.
- 목록에서 선택한 뒤 상세를 찾기 어려운 동선: 목록 하단에 현재 선택 이름과 상세 이동 버튼을 추가했다. 지도에도 대상 이름이 포함된 상세 이동 버튼을 제공한다.
- 상세 이동 시 제목이 화면 위에 걸리던 상태: 카드 전체가 16px 여백과 함께 보이도록 했다.
- 정찰 시작·완료 시 사라지던 키보드 초점: 진행 중 버튼의 초점을 유지하고, 갱신되는 상세 조작에 안정된 ID를 부여했다. 관련 없는 보고서는 재렌더하지 않으며 관련 보고서의 초점과 스크롤도 복원한다.
- 검색 중 재생성되던 입력 상태 위험: 검색 입력을 유지하며 IME 조합 중에는 필터링하지 않는다. 공백은 입력 그대로 보존하고 검색 비교에서만 정규화한다.

검수 결과 지도에서 대상 선택 → 필요한 관측 정보 확인 → 보고서 확인의 연결이 기존 연구·함대 화면과 일관된다. 작은 화면에서 이름을 표식에 모두 밀어 넣기보다 번호·선택 메뉴·목록을 함께 사용해 읽기와 터치를 확보했다.

## 검증 근거

- `npm test -- --maxWorkers=2`: 26파일, **250/250 통과**.
- `npm run build`: TypeScript 검사와 정적 빌드 통과.
- `npm run verify:build`: 정적 산출물 제공 검사 통과.
- `node tools/verify-uiux-polish.mjs`: **28개 통합 검사 통과**, 기존 행성 관제 15개 상태·화면 조합도 통과.
- 은하 화면 1440×900, 839×1065, 390×844, 320×568, 844×390: 가로 넘침·클릭 영역 겹침 없음, 텍스트 대비 검사 통과.
- 320/390/844px에서 실제 CSS 글자 크기 200%: reflow·지도 표식 영역·하단 내비게이션 검사 통과.
- 브라우저에서 관측 대상과 보유 행성 분리, 검색 초점·빈 결과 복구, 성역 전환, 기본 Back, 보고서 출처, 원래 대상에 정찰 결과 귀속, 오프라인·초기화 취소, 자산 불변 검증.
- 별도 코드 검토에서 보고된 지연 완료 초점 문제를 수정하고 회귀 검사를 추가했다. 남은 중요 지적 없음.

Chrome 반응형 모드에서 390px·320px·844px 화면을 직접 조작하고 캡처를 확인했다. 실물 iOS/Android 기기 검수는 이 기록의 범위에 포함하지 않는다.

자동 검증 캡처·JSON과 직접 검수 캡처는 [검수 근거](../qa/2026-10-15-galaxy/)에 보존한다. 전체 검사 중 한 차례 기존 guild 테스트의 임시 포트가 Node fetch의 금지 포트에 해당해 실패했으며, 해당 테스트 재실행과 최종 전체 250개 재실행은 통과했다. 기존 모션 검사의 비동기 미디어 변경은 실제 일시정지·재생 상태를 기다리도록 검증 도구를 보완했다.

## 연결 범위와 코드

새 화면·데이터는 `public/uiux-demo/galaxy.js`, 스타일은 `galaxy.css`에 격리했다. `main.js`의 로컬 타이머와 `navigation.js`의 대상 URL을 연결한다. UI 상태·보고서에는 API·저장소 호출이 없다. 검수 중 API 요청·비GET 요청·Storage 접근·런타임 오류는 0건이다. 게임 API 4318은 실행하지 않았고 작업 폴더의 게임 DB도 생성되지 않았다. `src/` 변경은 없다.

시연 보고서는 새로고침이나 초기화로 사라진다. 좌표·대상 배치·관측 신호는 화면 검토용 예시이며 실제 우주 데이터나 정찰·전투 규칙을 구현한 것이 아니다. 배포·커밋·푸시는 수행하지 않았다.
