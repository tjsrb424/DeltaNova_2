# 그래픽 원본·후보 검토·실행 자산

2026-10-16 · 독립 데모 전용 · 기준 `766b248`

사용자의 승인된 함대 화면 재질과 Minimal Galactic Command를 기준으로 제작했다. 래스터는 imagegen으로 생성/편집하고, 기능 아이콘은 정밀한 경로를 제어할 수 있는 코드 벡터로 제작했다. 사용자가 지적한 거친 SVG 도해를 단순히 확대하지 않았다. 생성 결과를 곧바로 실행 폴더에 넣지 않고 후보 검토·수정·재검토 후 채택했다.

점수는 제작자와 별도 읽기 전용 리뷰의 **주관적 내부 시각 판단**이다. 자동 AI 노이즈 탐지·품질 인증·사용자 승인으로 해석하지 않는다. 기준은 실루엣/구조, 잔선/노이즈, 재질/스타일, 실제 표시 크기, 투명도/실행 비용이며 **9.5점 초과** 후보만 채택한다. 발견된 결함은 수정하거나 후보를 반려했다. 아직 발견하지 못한 결함이 없음을 증명하는 점수는 아니다.

원본/실제 크기 검토에서 녹은 패널, 근거 없는 부속물, 떠 있는 조각, 문자 흔적, 셀 간 침범과 투명 경계의 프린지를 확인했다. 시설의 작은 표현은 건물의 기능을 설명하는 보조 삽화이며 시설명/비용/상태를 대신하지 않는다. 기존 행성/함선/도약문은 이전 커밋의 자산을 재사용했으며 위의 새 후보 점수를 소급 부여하지 않았다.

## 재현·추적

- `prompts.json`: 최초 시설/연구/우주 프롬프트 원문.
- `facility-edit-prompt.txt`: 시설의 셀 침범을 수정한 imagegen 편집 프롬프트.
- `facilities-v1.png`: 반려 원본 보존. 실행 경로에서 사용하지 않는다.
- `facilities-v2.png`, `research-v1.png`, `space-v1.png`: 채택 원본.
- `neon-candidate-v1.js`, `neon-candidate-v2.js`, `neon-candidate.js`: 벡터 수정 이력. 마지막 파일이 채택V3이며 `public/uiux-demo/icons.js`와 동일하다.
- `neon-review.html`: Vite에서 `/docs/art-source/visual-unification-v1/neon-review.html`로 후보 검토 시트를 재현한다.
- `review-gate.json`: 채택 상태/점수. `facility-cell-bounds.json`: 셀 경계 측정.
- `manifest.json`: 원본과 실행 파일의 SHA256/크기/매핑.
- [원본 크기/작은 크기 시트 및 실제 화면](../../qa/2026-10-16-visual-unification/README.md).

실행 자산은 원본을 paint/재합성하지 않고 sharp로 크기 조정·WebP 인코딩했다. 시설1200×800 quality86 alphaQuality100, 연구1600×533 quality84, 우주1600×533 quality84. 추가 래스터 합계 **273,694bytes(약267KiB)**. 새 실행 라이브러리는 없다. 버전이 다른 코덱의 재인코딩은 바이트 동일성을 보장하지 않으므로 게시한 WebP와 해시를 기준으로 사용한다.

생성 도구는 후보 원본의 메타데이터 외 고정 seed/model revision을 제공하지 않았다. 원문 프롬프트와 최종 원본을 함께 보관해 재작업의 기준을 유지한다. 그래픽을 변경하면 현재 점수를 재사용하지 말고 같은 크기로 재검토한다.
