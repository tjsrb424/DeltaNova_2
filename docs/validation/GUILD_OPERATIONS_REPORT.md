# 공동 작전 구현 검증 — 2026-10-13

## 구현 범위

`도약문 재가동` 공동 작전, 개발 참가자 네 명, 역할 예약/해제/만료, 준비 임무 전투와 생존 조건, 결합 지원을 받는 돌파, 개인·공동 공헌 보상, 다음 작전 개설을 구현했다. 서로 다른 HTTP 세션이 같은 서버 상태를 사용하며 React 공동 작전 메뉴에 연결했다.

준비 역할은 정찰·교란·보급이다. 정찰함의 생존 승리로 적 드론을 줄이고, 전자전함으로 첫 사격을 차단하고, 회수함으로 실제 운반한 보급으로 교전 사이 HP를 회복한다. 돌파는 두 교전의 실제 로그와 적용된 기여자, 복구량, 생존 함대를 보고한다. 지원이 없어도 돌파를 시도할 수 있다.

상태와 명령 영수증을 SQLite 한 트랜잭션으로 기록한다. 동일 명령은 이전 결과를 반환하고, 상태 버전 충돌은 새 명령으로 자동 재시도하지 않는다. 화면은 낮은 버전의 응답을 무시하며 통신 실패 중 확정 기록을 유지한다. 미확정 명령은 동일 ID로 재전송한다.

## 검증 증거

- `npm test`: 6개 파일, 73개 테스트 통과. 기존 개인 작전 45개 + 공동 규칙 9개 + 실제 HTTP/SQLite 7개 + 공동 UI DOM 12개.
- `npm run build`: TypeScript 검사와 Vite production build 통과.
- `npm run verify:build`: 빌드 HTML/JS/CSS/기지 아트의 루프백 HTTP 제공 통과.
- `npm run verify:guild`: Vite proxy와 실제 API/임시 SQLite를 통해 독립 세션 네 개가 모든 역할을 수행. 세 지원 결합·보급 복구·공동 성공·각 30 공헌·중복 명령의 무지급을 확인. 임시 서버 종료.
- 서버 테스트: 같은 역할 경쟁, 타인 조작/위조 필드/허용하지 않은 Origin 거절, 중복 및 ID 재사용 차단, 재시작 후 영수증 복구, SQLite 영수증 쓰기 실패 시 전체 롤백, 미래 버전 DB 원본 보존, 두 참가자의 공유 성공.
- DOM 테스트: 연결→예약→편성→기여, 연결 실패/복구, 지연 읽기 무시, 참가자 전환 후 이전 응답 무시, 미확정 명령 재전송, 세션 만료 및 미확정 중 참가자 전환 잠금.

브라우저·에디터·렌더러 창을 열지 않았다. 레이아웃의 실제 렌더, 모바일 기기, 애니메이션 체감, 사람 사이 협동 재미는 이 검사로 확정하지 않는다.

## 독립 검토와 수정

별도 검토자가 `105bbcb..480a5cb`를 읽기 전용으로 검토했다. Critical 0, Important 3, Minor 0이었다. 다음 세 문제를 먼저 실패 테스트로 재현하고 수정했다. 수정 후 전체 73개 테스트, 빌드와 공동 HTTP smoke가 통과했다. 재검토를 완료했다고 주장하지 않으며 수정은 회귀 테스트로 검증했다.

1. 3초보다 느린 읽기가 다음 폴링에 밀려 계속 무시됨 → 세션별 읽기를 한 번에 하나만 진행. 4초 응답/3초 간격 재현이 통과했다.
2. 서버 재시작 뒤 401이 미확정 명령을 지움 → 명령 ID·payload를 보존하고 동일 참가자의 새 토큰으로 원래 영수증을 확인. 응답 유실→401→재연결→중복 영수증 재현이 통과했다.
3. 메뉴 이동 시 미확정 명령이 사라짐 → 탭 저장과 메모리 보존을 추가. 새 클라이언트 인스턴스의 저장 복원과 저장 거절 상태의 메뉴 재진입 모두 동일 명령으로 복구했다.

보류한 경미한 코드 지적은 없다. 검토에서 제외한 실제 계정/공개 운영, 렌더/모바일/모션, 장기 경제는 사용자의 전체 목표에는 포함되며 후속 단계로 유지한다. 각각 별도 서비스 검증, 시각·사용성 수정, 보상·비용 재조정의 비용이 남는다. Git 제외 검토 임시 자료는 보존했다.

## 결정과 제한

- 사용자의 추천안 진행 위임에 따라 추가 승인 대기 없이 로컬 개발을 진행했다. 잘못된 세부 방향은 로컬 구현을 수정하는 비용이 든다.
- 기존 전용 개발 브랜치를 이어 사용했다. 향후 동시 작업이 생기면 별도 작업 공간이 필요하다.
- 상태와 영수증의 부분 저장을 막기 위해 Node24 내장 SQLite를 선택했다. 현재 런타임은 실험 API 경고를 출력한다. 런타임 변경 시 저장 어댑터 검증·교체 비용이 생길 수 있다.
- 개발 참가자 선택은 계정 인증이 아니다. 서버는 현재 PC 루프백 전용이며 인터넷 배포·계정·길드 가입·장기 운영 기능을 포함하지 않는다.
- 개발용 9척 함대와 고정 보상이다. 함대 영구 보유권·생산 경제·공헌도 소비처는 후속 단계다. 개인 로컬 저장 스키마는 변경하지 않았다.
- 역할별 서버 연산은 즉시 판정하며 실시간 전투 애니메이션은 추가하지 않았다. 전술 도식, 역할 상태, 선택/버튼 피드백과 로그를 제공한다.
