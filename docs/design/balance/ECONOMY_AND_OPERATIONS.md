# 생산·건설·연구·함대 운영 규칙 v0.1

2026-10-14. [통합 기획](../DELTA_NOVA_CONTENT_BALANCE_V0.1.md)의 추천 규칙이다. 수치는 [카탈로그](catalog.mjs), 실제 계산 범위와 한계는 [검증 보고서](BALANCE_AUDIT_V0.1.md)를 따른다. 기존 런타임에 적용되지 않았다.

## 시작과 기본 경제

새 시즌은 본성1개, 합금8,000·결정5,000·연료3,500, 생산시설3종·발전소·저장고·조선소·연구소 각1레벨로 시작하는 안이다. 정찰함 위스프·수송선 캐러밴·타격함 케스트럴을 각1척 제공한다. 초기 시설 단계는 무료이고 다음 레벨부터 비용을 지불한다. 초기 함선은 재출격마다 다시 지급하지 않는다. 기존 시제품의 초기9척과 저장은 이 기획으로 바꾸지 않는다.

시간 단위는 실제 시간이며 접속한 시간만 생산하지 않는다. 생산시설의 기본 시간당 생산은 합금120·결정90·연료70에 `L × 1.10^(L-1)`을 곱한다. 자동화 보너스는 모든 자원에 최대24%, 정밀 정제는 결정·연료에 추가 최대12%로 가산한다. 한시적 이벤트 버프는 시즌 주 성장 모델에서 제외한다.

초기 저장고는 자원마다6,000이다. 기본 생산 대비 각각50·66.7·85.7시간을 담는다. 압축 저장과 저장고 레벨로 확장한다. 12~24시간 접속 공백을 기본 정상 운영으로 취급하고 현재 시제품의8시간 생산 상한은 시즌 기본안에서 제거한다. 생산은 저장 상한까지만 쌓이며 포화 손실·전력 부족·융합 발전 연료 부족은 안내한다. 모든 생산 수령 버튼을 반복 클릭할 필요는 없다.

저장고를 올릴지는 `현재 생산률 × 36시간`과 **다음 투자에서 필요한 각 자원의 가장 큰 비용**을 모두 비교한다. 대형 함선1척 가격보다 작은 저장 상한을 가진 행성에서 그 함선을 무한히 기다리게 하지 않는다. 큐 시작과 수송 도착이 저장·예약 자원과 상호작용하는 결과도 사전에 보여준다.

## 전력과 공간

기본 발전소는 `100 × L × 1.15^(L-1)`의 전력을 공급한다. 생산시설 수요는 합금8·결정9·연료10에 각 시설의 `L × 1.10^(L-1)`을 곱하고 전력 효율 연구를 적용한다. 기타 시설은 카탈로그의 상시 전력/레벨을 적용하고 방어 설비는 기당 전력을 사용한다.

전력 부족 시 생산률에 `min(1, 공급/수요)`를 곱한다. 같은 전력을 생산과 방어에 동시에 무제한 사용하지 않는다. 실제 위협 때 활성 시설·방어 설비 우선순위 선택을 제공하는 안이며 정지한 설비는 보유 규모 점수에는 남아도 실제 전투에 정상 기여하지 않는다. 융합 발전은 시간당 연료12×레벨을 소비한다. 연료가 모자라면 해당 발전이 정지하고 다른 생산·방어 상태를 다시 계산한다.

본성은 공간120, 식민지는100을 기본으로 두며 환경 조정소는 레벨당15를 추가한다. 시설은 표의 공간×레벨, 방어 설비는 기당1을 차지한다. 초기 본성 시설은 공간9를 사용한다. 진행 작업은 완료에 필요한 추가 공간을 예약한다. 공간을 예약한 다른 명령과 동시에 같은 공간을 소비하지 않는다. 가동 중단으로 공간이 반환되지는 않는다.

## 건설·연구·건조 계획

현지 건설1개, 함선 건조1개, 방어 설비 건조1개, 제국 연구1개를 병행한다. 완료는 서버 사건이다. 접속이 없어도 이미 시작한 작업과 지급을 처리한다. 현지 기본 건설 계획3개·제국 연구 계획3개·함대/방어 건조 계획3개를 추천한다. 식민지 행정소의 건설 계획 증가와 함대 수량 입력은 별도로 관리한다.

계획은 단순 목록이며 시작하지 않은 작업은 자산·연구 효과가 아니다. 이 초기 추천안은 예약한 계획의 실제 비용을 자원별로 묶어 중복 사용을 막는다. 선행 작업이 취소되거나 조건이 사라지면 뒤 작업을 중단하고 원인을 보여준다. 무한한 미래 자원을 가정해 모든 레벨의 비용을 선지출시키지 않는다. 자동 투자 정책과 수송 반복 계획은 사용자 지정 예산·중단 조건이 있어야 한다.

| 작업 | 기본 시간과 속도 보정 |
|---|---|
| 시설 | 카탈로그 기본 시간×1.45^(L-1) / (1+건설 공학 보너스) |
| 연구 | 카탈로그 기본 시간×1.5^(L-1) / (1+0.10×(시작 연구소 레벨-1)) |
| 함선 | 1척 기준 `max(0.25시간, 표준 비용 합계/6,000)`×수량 / (1+0.12×(조선소 레벨-1)+조립 시설0.05×레벨+선체 조립 보너스) |
| 방어 | 1기 기준 `max(0.25시간, 표준 비용 합계/6,000)`×수량 / (1+0.12×(제작소 레벨-1)+선체 조립 보너스) |

연구소의 이전 레벨로 시작한 연구는 뒤 시설 완공으로 완료 시각을 소급 변경하지 않는다. 모든 속도 조건은 작업 시작 때 고정하는 안이다. 건조의 지급은 주문 단위 완료 때 전체 수량을 한 번 지급한다. 긴 대량 주문은 예상 시간과 작은 배치 선택을 보여준다. 일부 완성 함선을 먼저 지급하는 후속 규칙은 따로 승인·검증한다.

아직 시작하지 않은 계획 취소는 예약 비용100%를 풀고, 진행 작업 취소는 실제 지불 비용80%를 같은 행성으로 반환한다. 완료한 작업은 취소하지 않는다. 반환으로 저장 상한을 넘으면 현재 시제품처럼 공간 부족을 안내하고 취소를 거절한다. 취소·재예약으로 순위나 생산 보너스를 반복 얻지 않는다.

## 출격·항로·연료·적재

현재 출발 행성에 있는 함선만 편성한다. 원거리 주둔·수송·공격·귀환의 함선은 다른 행성에서 복제하지 않는다. 기본 출격 지휘 용량은100, 함대 지휘 연구는 레벨당50, 현지 지휘본부는 레벨당50을 더한다. 이는 단일 출격의 용량이며 제국 전체 보유량이나 기존 연습의6척 제한과 다르다. 같은 가용 함선을 여러 출격에 예약할 수 없다.

후보 거리 단위 D에서 한 편도 이동은 `max(0.75시간, 0.5시간 × D × 100/편대 최저 유효 속도 / 운항 비율)`이다. 운항 비율은50%·75%·100% 중 선택한다. 가까운 항로의100속도 함선도 최소45분이며, 느린 함선1척을 넣으면 편대 전체가 늦어진다. 거리 단위의 실제 은하 좌표 매핑은 세계 설계에서 확정한다.

유효 속도는 함종에 맞는 엔진 한 종류와 항행·항로 비콘 보너스를 가산하며 총 보너스50%를 상한으로 둔다. 기본 L 함선은 화학, M은 이온, H는 융합을 사용한다. 엔진을 세 종류 모두 연구해 한 함선에 중첩하지 않는다. 해당 상위 엔진이 없어도 이미 해금된 함종은 기본 속도로 이동한다.

왕복 연료는 `ceil(2 × D × Σ(척수×함종 기본 연료) × 운항 비율^1.6 × (1-연료 효율 보너스))`이다. 초기안은 출격 때 왕복 연료를 확보해 귀환 불능을 막는다. 단방향 재배치는 편도 비용을 사용한다. 실제 협공 대기·추가 항로·귀환지 변경의 연료 정산은 상세 이동 설계에서 따로 다룬다. 시간 감소와 연료 감소를 같은 방향의 무제한 보너스로 만들지 않는다.

적재량은 `Σ(척수×기본 적재) × (1+화물 압축 보너스)`다. 연료와 화물의 예약 위치를 따로 기록하고 같은 자원을 행성 비축과 이동 화물에 이중 저장하지 않는다. 약탈은 노출 자원·회수 가능량·적재·연료·손실·수리·시간으로 순수익을 판단한다. 상한 초과 화물의 반송 규칙은 [식민지 방향](../DELTA_NOVA_COLONIES_V0.1.md)을 따른다.

## 정찰과 대응

센서 시설은 접근·침입 탐지, 센서 해상도·침투 정보학·함종은 보고서 해상도, 암호화는 정보 노출 억제를 담당한다. 한 기술로 세 효과를 모두 무제한 올리지 않는다. 정찰 공격 지수는 센서 연구5×레벨+침투 연구5×레벨+정찰 함종 지수의 합이다. 기본 정찰함은 척당5, 침투 정찰함은 척당15를 제안하며 함선 기여의 합은40이 상한이다. 저가 함선 수량만으로 기술 투자를 완전히 대체하지 않는다. 이 규모 지수도 실제 보내는 전력·연료·탐지 위험을 지불한다.

보고서 순 해상도 지수는 공격 지수-상대 암호화5×레벨이다. 0미만은 존재 확인, 0~9는 자원 범위, 10~24는 함대 규모 범위, 25~39는 함종·방어 범위, 40이상은 관측 시각의 자세한 자산 보고를 후보 단계로 둔다. 기술·시설 상세 노출과 침투 성공 조건은 상대 탐지와 함께 다음 정보전 검증에서 정한다. 미확인 정보를0으로 표시하지 않는다.

탐지 지수는 현지 센서 배열10×레벨+센서망10×기수+센서 연구5×레벨을 기본으로 삼는다. 무한한 센서망 기수로 탐지 지수를 쌓는 문제를 막기 위해 시설 센서망의 합산은50으로 제한한다. 탐지 성공 함수·위스프/쉐이드 노출 지수·검증 가능한 확률은 미확정이며 위 지수만으로 확률값을 만들어 보고하지 않는다.

## 전투·수리·영구 손실

기본 피해 후보식은 `표적별 공격 / (1+대상 장갑/100)`이며 방어막을 먼저 소모하고 선체를 깎는다. 병기·크기 계수는 함대 카탈로그를 따른다. 동시 피해·집중 사격·편대 배치·철수 사건의 상세 실행 순서는 후속 전투 설계다. 기존 연습의 장갑 단순 차감과 모든 적을 시설/이동형 두 가지로 분류한 엔진에 이 수치를 그대로 끼워 넣지 않는다.

운동탄·빔·미사일은 해당 연구 최대30%를 적용한다. 공성과 드론은 공성 교리·함재 운용의 최대24%를 적용하며 두 무장 연구를 동시에 합산하지 않는다. 선체·방어막 연구는 각자의 기본 값에만 적용한다. 편대의 호위·방어막 지원·방호 편대 피해 경감은 합계15%가 상한이다. 전자전의 방어막 약화는 투자 비중에 비례하고 편대 합계20%가 상한이며 주파수 복원은 최대12%p를 상쇄한다.

선체0은 영구 파괴로 제안한다. 선체가 남은 작전 불능 상태는 예인·정비의 대상이고 파괴된 함선은 새로 건조한다. 방어막은 귀환 후 전력이 있으면1시간에 재충전하되 선체를 무료 회복시키지 않는다. 정비의 자원 비용은 각 함선의 표준 합금·결정 비용×손상 비율×수리 계수(기본20%, 연구 후 최저16%)다. 연료 건조 재료는 수리 비용에 재청구하지 않는다.

선체 수리 시간은 원래1척 기본 건조시간×손상 비율×0.25/(1+정비 도크0.10×레벨)다. 멘더의 현장 수리는 같은 재료를 싣고 최대2회에 걸쳐 생존 함선 손상만 복구하는 안이며 각 회복량과 소모 자원을 보존한다. 전투 중 무한 회복이나 무자원 완전 수리는 사용하지 않는다.

영구 파괴의 잔해는 표준 합금·결정 비용의30%이며 잔해 분리 연구로 최대45%다. 연료는 회수하지 않는다. 잔해는 실제 장소·소유/접근 조건·적재를 갖고 회수 전에는 비축 자원이 아니다. 같은 전투의 회수·수리·점수·보상을 재실행해 복제하지 않는다. 물량 손실과 잔해 회수는 전쟁 성과의 영구 손실 판정을 바꾸지 않는다.

방어시설은 전투 결과에서60% 작전 불능·40% 영구 파괴로 나누는 초기안을 별도로 검증한다. 작은 기수에서도 비율을 무상 이익으로 악용하지 않도록 사건 ID와 기수로 결정적인 나머지 처리를 정해야 한다. 작전 불능 시설의 복구는 합금·결정 표준 비용의35%를 지불하며 무료 즉시 재건이 아니다. 성장 시설·본성 소유권은 일반 습격으로 삭제하지 않는다. 점수는 영구 파괴40%에만 반영하고 수리된60%를 반복 파괴 실적으로 계산하지 않는다.

일반 습격의 회수 후보 상한은 보호 창고를 제외한 노출 자원의25%다. 신규 보호·전력 차 보호·같은 상대의 반복 약탈 한도는 별도의 PvP 설계에서 정한다. 이를 현재 서버에 적용한 약탈 규칙으로 보고하지 않는다. [시즌 랭킹](../DELTA_NOVA_SEASONS_AND_RANKINGS_V0.1.md)의 전투 규모 보정과 반복 교전 감쇠는 점수 규칙이며 공격 허용과 같은 기능이 아니다.

## 개척과 복수 행성

식민지 운영1레벨마다 추가 식민지1개, 본성 포함 최대5개를 추천한다. 개척선 파이오니어는 성공 때 소비하고 실제 초기 화물을 보내야 한다. 개척 비용은 개척선12,500자원과 현지 정착 꾸러미 합금4,000·결정2,500·연료1,000 및 실제 비행 연료다. 정착 꾸러미는 최소 시설 재료에 사용되며 해당 화물을 받았다고 본성 레벨·자원을 복사하지 않는다.

꾸러미는 초기 생산3종·발전·저장1레벨을 설치하는 별도 일회성 개척 배치 비용이다. 이 시설의 성장 점수는 무료 초기 단계와 같이0이고, 소모된 꾸러미의 비용을 시설별 표준 가격으로 다시 중복 점수화하지 않는다. 조선소·연구소·방어는 따로 투자한다. 기술은 제국 공통이고 시설·자원·주둔 함대는 현지다.

생산 입지 보정은 초기 후보에서 특화 자원+15%, 다른 자원 중 하나-10%를 첫 범위로 둔다. 시작 본성은 공통 기준 생산으로 두고 식민지의 특화 선택에만 적용한다. 항로 교차 거점은 생산 이득 대신 위치를 제공한다. 확장 보너스를 기지 개수만으로 제국 전체에 무한 가산하지 않는다.

## 하루 1~2회 관리에서 필요한 화면과 동작

접속 때 제국 요약에서 포화까지 시간·전력·완료/중단 작업·가용/외출 함대·위협 도착·수송 부족을 본다. 우선순위는 위험 대응, 중단된 계획 해소, 다음 건설/연구/건조 예약, 정찰 보고 확인과 출격이다. 화면은 예산과 부족 자원을 보여주고 진행 목록은 각 행성과 완료 시각을 명시한다.

오래 접속할수록 생산 자체가 늘어나는 수령·채굴 클릭은 두지 않는다. 명령과 작업 계획·사전 철수 조건은 접속 공백을 감당하도록 준비하되, 모든 위험을 자동으로 해결하는 무료 완전 방어로 만들지 않는다. 실제 접근 알림의 채널·동의·설정은 운영 설계 대상이며 이 작업에서 외부 메시지를 보내지 않는다.
