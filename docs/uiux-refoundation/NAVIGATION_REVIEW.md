# 중앙 메뉴와 빠른 상세 검수

2026-10-15 · `codex/uiux-refoundation` · 독립 데모만 수정 · 로컬 미커밋

## 반영한 흐름

- 왼쪽 건설·연구·함대·작전·은하·동맹·보고서·편성 연습은 중앙 내용을 교체한다. 메뉴 선택 표시와 제목을 함께 바꾸고 160ms의 작은 페이드만 사용한다. 데스크톱 메뉴는 스크롤 중에도 접근할 수 있다.
- 모바일 더보기는 중앙 메뉴 화면이다. 자원, 개별 시설, 함대·연구 요약, 위협, 정찰 위성과 화면 설정만 짧은 오른쪽 상세로 표시한다. 요약에서 전체 관리로 이어진다.
- 건설에는 현지 대기열, 시설 목록, 증설 전후, 현재 보유·비용·가상 잔량, 조건이 함께 나온다. 연구소·조선소 확인 링크는 해당 시설을 직접 선택한다.
- 모바일 시설 선택은 작은 고정 선택 바로 유지한다. 상세 내용만 갱신해 선택 컨트롤을 재생성하거나 자동으로 스크롤하지 않는다. 오른쪽 개별 시설 선택도 포커스와 패널 스크롤을 유지한다.
- 평시에도 선택 행성의 방어 수량을 표시한다. 노바의 위협 대상과 현재 선택 행성은 별도로 제시한다.
- URL에 중앙 화면과 짧은 상세를 표현하고 브라우저 뒤로·앞으로 가기에 연결했다. 원래 선택 시설, 읽던 위치와 포커스를 복원하며, 직접 연 상세 URL도 데모 안에서 닫힌다. 숨겨진 닫기 버튼으로 포커스를 복원하지 않는다.
- 빈 상태에는 관련 건설·연구·함대 등으로 이어지는 이동을 제공한다. 공통 예시 안내는 상단과 패널 헤더에 두고 명령 비활성화 이유는 간결하게 표시한다.

## 검증 근거

- 전체 Vitest: **25개 파일, 224개 테스트 통과**.
- `npm run build`, `npm run verify:build`, 독립 데모 모델 검사 **6개 통과**, `git diff --check` 통과.
- 정적 빌드만 임시 loopback에서 제공하는 `tools/verify-uiux-polish.mjs`: **22개 통합 검사, 평시·접근·완료 15개 레이아웃 통과**.
- 주요 메뉴와 더보기의 모든 하위 화면을 1440×900, 839×1065, 390×844, 320×568, 844×390에서 확인했다. Back/Forward, 상세 닫기·Escape·포커스 복귀, 직접 URL, 로딩·빈 상태, 200% 텍스트 확대, 가로 넘침·텍스트 대비를 검사했다.
- 행성 자전, 독립 구름층, 위성 가림, 행성 밖 항로·위치·ETA, 도착 효과와 모션 감소 검사를 유지했다. 모션 검사는 마지막 프레임이 합성된 후 픽셀을 비교하고 남은 예시 시간 기준으로 도달 구간을 검사한다.
- 인앱 브라우저에서 데스크톱 건설, 모바일 건설·연구·함대·더보기, 가로 방어 화면을 직접 보았다. 모바일 고정 선택 바는 실제 좌표 클릭과 키보드로 조작했으며 **scrollY 764.8, 선택 바 top 20.8이 시설 변경 전후 유지**됐다. 도구의 locator 자동 포커스로 생기는 스크롤과 구분해 확인했다.
- 독립 코드 리뷰에서 발견한 개별 시설 선택 포커스, 오프라인 표시 유지, 직접 상세 URL 닫기 포커스, 시설 선택 표식, 가로 홈 포커스 문제를 수정하고 재검증했다.

자동 검사 결과와 대표 화면은 [검수 자료](../qa/2026-10-15-navigation/)에 있다.

## 범위와 한계

게임 API·DB·운영 UI는 연결하거나 변경하지 않았다. 브라우저 검사에서 API/비 GET 요청, Storage 접근, 실행 오류는 0건이었다. 검수 후 게임 API 포트 4318의 리스너는 0개, `.delta-nova/guild.sqlite`는 존재하지 않았다. 프런트엔드 정적 데모는 5180에서 유지한다.

모든 자원·비용·함대·연구·방어는 기존 예시 스냅샷이다. 실제 건설·함대 이동·정찰 명령은 비활성화되어 있다. 은하·동맹 등 미연결 화면의 정보 구조와 복귀 흐름까지 반영했으며 실제 게임 기능 구현을 뜻하지 않는다. 로컬 시연 시간은 짧은 상세를 보는 동안 멈추며, 실제 서버 ETA에 적용할 규칙은 아니다.
