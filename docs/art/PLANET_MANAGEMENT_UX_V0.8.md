# 행성 관리 UX v0.8

2026-10-14 사용자가 Stellaris 행성 관리 UI를 주 레퍼런스로 삼는 개발 방향을 승인했다. 기존 DeltaNova 화면의 조작·정보 배치를 개편하는 범위이며, 서버 규칙이나 게임 시스템을 추가하는 작업은 아니다.

## 레퍼런스와 적용

[Stellaris 공식 개발일지 #389의 Planet View Improvements](https://store.steampowered.com/news/posts/?appids=281990&enddate=1756138889&feed=steam_community_announcements)는 행성 요약과 건설 대기열을 함께 표시하고 건설 후에도 목록을 유지하는 조작 흐름을 제시한다. 해당 2025년 사례의 정보 배치와 동작 원칙을 적용했다. DeltaNova의 밝은 세라믹 작업 영역, 흑연색 메뉴, 청록색 선택·실행, 자체 시설 자산을 유지한다.

| 원칙 | 실제 구현 |
|---|---|
| 현황과 상세의 역할 구분 | 메인은 현재 기반·진행 중 투자·완료 효과·생산·함대 준비 상태, 카테고리는 전체 본문 전환 |
| 공통 정보의 간결한 배치 | 자원·생산·전력·공간 HUD, 참가자 설정 접기, 새로고침과 오류·재전송 노출 |
| 목록 → 선택 → 비교 → 실행 | 건설의 짧은 시설 행, 실제 생산·저장·여유 전력·공간 변화, 비용·시간·불가 사유·실행 |
| 건설 후에도 선택 유지 | 명령 수락 후 시설 목록과 선택한 시설을 유지하며 작업 슬롯의 사용 상태 표시 |
| 진행 중 작업을 쉽게 확인 | 1200px 이상 옆 대기열, 이하 본문 위 접이식 대기열, 작업명으로 원래 행성·대상 상세 이동 |
| 작은 창의 조작 보장 | 목록과 본문 스크롤, 44px 이상 실행 버튼, 높이가 부족하면 장식 축소 및 일반 스크롤 전환 |

## 공간이 부족할 때

- 720px 이하: 가로 카테고리 메뉴와 시설 목록. 각 메뉴와 시설은 가로 스크롤로 접근한다.
- 750px 이하 높이: 건설 상세의 큰 시설 그림·중복 출처를 생략하고 증설 효과를 먼저 표시한다.
- 실제 상세 영역이 260px보다 작으면 고정 실행 영역이 효과 표를 덮지 않도록 일반 흐름으로 전환한다. 이 상태에서는 효과와 실행 영역을 스크롤해서 확인한다.
- 540px 이하 높이: 전체 문서가 자연스럽게 스크롤된다. 가로 메뉴는 화면 전체 높이를 차지하지 않는다.
- 같은 카테고리에서 시설을 바꿀 때 키보드 포커스를 유지한다. 카테고리를 바꾸면 본문 시작으로 이동한다.

## 수치의 범위

선택한 시설 1회 증설의 효과는 `productionRates`, `capacities`, `power`, `facilitySpace`로 계산한다. 다른 진행 중 작업은 이 비교에 합산하지 않는다. 최대 시설 수준에서는 추가 효과를 제시하지 않는다. 발전소 증설은 전력 부족으로 감소한 현재 생산과 복구된 생산을 비교한다. 연구소는 실제 다음 기술 수준의 시설 조건을 충족할 때만 해당 기술을 안내하며, 공통 연구 최대 Lv.3를 넘는 새 연구 수준을 약속하지 않는다.

보유 자원 예측, 행성 전체 경험치·성장 점수, 자동 연속 건설, 새 성계·식민지 기능은 구현하지 않는다.

## 검증 및 사용자 검수

검증 결과·캡처·실제 API 동작과 사용자 확인 순서는 [QA 기록](../qa/2026-10-14-planet-management/README.md)에 있다. 전체 자동 검증과 독립 코드 리뷰를 거쳤다. 최종 조작감·미술 선호에 대한 사용자 검수는 별도다.
