# 행성 운영보드·성장 상세 검증 기록

날짜: 2026-10-14. 사용자 승인: A 운영보드 메인 + B 성장 상세.

## 구현 결과

- 큰 행성 장면을 작은 행성 식별 요소로 줄이고, 메인에 생산·저장·전력·함대 상태, 현재 개발의 완료 효과와 다음 행동을 표시한다.
- 건설·함대·연구·개인 작전·보고서 선택 시 본문 전체가 해당 상세 화면으로 전환된다. 동맹은 기존 공동 작전으로 연결된다.
- 연구 상세의 발전지도와 건설·함대의 펼침 지도는 실제 시설·기술 조건 및 부족한 재료를 계산한다.
- 진행 중인 개발의 지불 금액과 타 행성의 공통 연구를 반영한다. 필요 발전소 증설 비용, 현재 전력 부족 및 목표 시설 공간 부족도 표시한다.
- 서버 API, 저장 스키마 및 게임 규칙은 변경하지 않았다.

헤드리스 검사 폭: PC 1672, 태블릿 900, 모바일 390px. 각 캡처에서 문서 가로 폭이 뷰포트 안에 들어오며 런타임 예외는 0이다. GUI 창이나 기존 사용자 브라우저 프로필을 사용하지 않았다. 실제 사용자 저장 데이터는 검사에 사용하지 않았다.

신규 동작 테스트는 본문 전환, 완료 효과 및 원본 상태 보존, 현지 손상 함선만 정비, 시설 선택 동기화, 아크 비용/부족분, 지불한 증설 제외, 타 행성 공통 연구, 발전소 회복 비용, 공간 부족 및 방어 연구 효과를 확인한다.

## 사용자 검수 순서

1. 실행 중인 `http://127.0.0.1:5173/`를 새로고침하고 필요하면 참가자로 연결한다.
2. 메인에서 시설 현황, 자원·전력, 진행 중 개발의 완료 효과와 다음 행동이 이해되는지 확인한다.
3. 건설 → 함대 → 연구 → 개인 작전 → 보고서 → 대시보드를 눌러 본문 전환을 확인한다.
4. 연구의 성장 목표 함선을 바꿔 요구 시설·연구, 총 비용·부족분을 확인한다.
5. 시설 카드를 선택해 선택 강조와 상세 폼이 일치하는지 확인하고, 화면 폭을 줄여 가독성을 검수한다.
