## 즉시 확인하는 방법

1. Python 3가 있다면 압축 해제 후 `python 08_VALIDATION/validate_static.py`.
2. `07_PROTOTYPE/index.html`을 Chrome 등 브라우저에서 열고 아래 항목을 직접 테스트.
3. PC 1920×1080, 1440×900 및 모바일 모드 390×844, 360×800에서 스크린샷 비교.
4. `적 함대 접근 시연` → `회피 계획 검토` → `닫고 돌아가기`로 경보 흐름 확인.
5. `행성 성장 단계 시연`과 `행동 완료 상태 시연` 버튼의 피드백 확인.
6. `Esc`, `Tab`으로 드로어 닫기/이동, OS 모션 감소 기능으로 애니메이션 감소 확인.

> `validate_static.py`의 통과는 데모 렌더링 및 게임 기능 완성/접근성 전체 통과를 의미하지 않습니다.
