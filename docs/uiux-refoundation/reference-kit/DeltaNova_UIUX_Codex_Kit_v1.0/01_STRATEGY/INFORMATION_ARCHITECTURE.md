# 정보구조 및 탐색 정책

## 정보구조 초안

```text
DELTA NOVA APP SHELL
├── 상단 글로벌 바
│   ├── 행성/좌표 선택기 (현재 대상 보존)
│   ├── 자원 압축 표시 (상세 클릭 시 생산·저장량)
│   └── 중요 이벤트·환경설정·프로필
├── 1차 내비게이션 (PC 사이드 / 모바일 바텀+더보기)
│   ├── 홈 (행성 관제)
│   ├── 건설
│   ├── 연구
│   ├── 함대
│   ├── 은하 (탐사·정찰 접점)
│   └── 더보기: 방어·외교·동맹·메시지·랭킹·설정
├── 컨텍스트 메인 영역
│   ├── 행성/함대/연구/은하지도 등의 화면별 최우선 시각물
│   └── 상황별 작업 패널(하나의 주패널 원칙)
└── 일관된 상호작용 레이어
    ├── 알림/경고
    ├── 비파괴 모달/드로어
    ├── 확인이 필요한 명령의 검토 화면
    └── 완료/실패 피드백
```

실제 메뉴 명칭과 위치는 현재 저장소에서 사용 중인 기능과 사용자 기대를 조사해 확정. 위 트리는 제안.

## 탐색 규칙

1. 행성 전환을 하면 모든 화면에서 **현재 행성 선택 상태**가 명확히 보인다.
2. 글로벌 자원은 모든 화면에서 동일한 단위/자리수/증감 표기 원칙을 따른다.
3. 화면별 핵심 행동은 하나만 'primary'로 강조하고, 같은 중요도 버튼을 남발하지 않는다.
4. PC에서 사이드 내비를 열고 닫아도 메인 콘텐츠의 핵심 정보가 사라지지 않는다.
5. 모바일에서는 더보기 메뉴로 분기하더라도 경보·함대 대응은 한 단계 이내 노출.
6. 모달/드로어 닫기 시 포커스가 호출 버튼으로 복귀해야 한다.
7. 실패 시 입력/선택 상태를 보존하고 오류를 같은 맥락 안에서 설명한다.
8. 게임 상태가 바뀌면 화면이 이를 반영하지만 사용자 선택 패널을 갑자기 닫지 않는다.

## 콘텐츠 우선순위 — 행성 메인

**기본으로 보임:** 행성명/현재 행성, 요약 자원, 현재 위험 상태, 주요 진행(건설 또는 연구), 다음 행동 1개, 행성 성장 비주얼.

**사용자가 열 때만 보임:** 자원 생산 상세, 연구 트리 상세, 건물 리스트, 함대 편성, 메시지 전문, 로그.

**즉시 노출:** 공격/위험 이벤트, 서버 연결 상태 상실, 실제 입력 실패나 명령 충돌.

## 반응형 정책

- 데스크톱 기준은 **1920×1080**. 1440×900, 1280×720, 1024×768도 검증.
- 모바일 **390×844**와 **360×800** 필수, 세로 우선. 상태별 CTA는 겹치지 않는 고정 영역 또는 하단 버튼 배치.
- 폭 1280 이상: 확장형 사이드 내비 + 중앙 행성 + 맥락 패널.
- 폭 769~1279: 간결한 레일 + 중앙 행성 + 필요시 슬라이드 패널.
- 폭 768 이하: 중앙 행성 비주얼 규모 축소, 중요 상태/행동 우선, 하단 내비로 이동.
- 높이가 낮은 화면에서는 적 경보·CTA가 fold 아래로 밀리지 않아야 함.

## 복잡성과 밀도의 세부 가이드

- 동시에 강조된 버튼은 화면 영역별 최대 1개. 경보가 최상위 우선순위를 가져갈 수 있다.
- 독립 카드 반복보다 공통 표/리스트/세그먼트를 우선. 카드가 중첩된 카드 구조 금지.
- 각 카드 제목은 `대상이 무엇인지`, 본문은 `현재 상태`, CTA는 `무엇을 하는지` 알려준다.
- 행성은 큰 시각적 중심이지만 게임 컨트롤을 가리는 overlay 텍스트 금지.
- 단위 없는 숫자 또는 설명 없는 색깔의 의미 부여 금지.

## 모바일 전환시 절대 잃지 말 것

- 현재 대상 행성 및 위험 이벤트 진입 경로.
- 자원 총량의 확인 방법.
- 함대/회피 화면으로 가는 명확한 길.
- 진행 중인 투자와 실패/성공 안내.
