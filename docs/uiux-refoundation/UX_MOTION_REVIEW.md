# 독립 데모 UI/UX·자전·항로 후속 검수

2026-10-15 · `codex/uiux-refoundation` · 기준 `91cf86e` 이후 로컬 수정.

후속 변경: 대칭 반구·고정 항로 시간은 [행성 외곽 항로·자전 후속 검수](./EXTERIOR_ROUTE_REVIEW.md)의 전체 경도 텍스처와 위치·시간 동기화로 대체했다. 아래는 이전 검수 시점의 이력이다.

## 반영 범위

- 시설을 선택해 현재/다음 수준의 효과, 예시 비용·시간과 필요 조건을 비교한다. 실제 건설 버튼은 비활성이다. `presentation.js`는 읽기 전용 비교 자료이며 실제 경제 견적을 대체하지 않는다.
- 자원별 생산·보유/저장 한도·가용/전체 함대를 구분한다. 모바일 요약을 행성 앞에 두고 헤더와 시연 도구를 압축한다.
- 상세의 이전 메뉴 복귀와 전체 닫기를 구분한다. Back은 시설·스크롤·호출 버튼을, Close는 본문의 호출 버튼을 복원한다. 모바일의 기존 게임 복귀 경로도 더보기와 편성 연습에 보존한다.
- 행성 표식으로 시설을 선택한다. 기존 아트를 구면에 투영해 약 4분 주기로 자전하며 광원 방향을 유지한다. WebGL 미지원 시 자연 아트 정지 화면, 이미지 오류 시 절차 지형을 표시한다.
- 청록 출항과 붉은 점선 접근의 네온 흐름을 시연한다. 시간은 고정 예시이고 함선·자원·시설은 바뀌지 않는다. 선택 행성이 바뀌어도 위협의 원 대상은 유지한다.
- 모션 감소·수동 정지·숨긴 탭·화면 밖 행성·열린 상세에서는 연속 자전을 멈춘다. 항로·경고 문구는 정지해도 남는다.

## 한계와 다음 확인

- 자전은 기존 정면 아트의 구면 투영이다. 보이지 않는 반구는 원본을 대칭 재사용하므로 완전한 360도 고유 지형은 전용 지형 텍스처 작업이 필요하다.
- 출항/접근은 시각 시연이다. 실제 목적지·이동 사건·도착 시각·전투 결과·재고 변경을 생성하지 않는다.
- 시설 변경은 예시 시설 수준과 비교 화면만 바꾼다. 표시된 생산/자원의 실제 재계산이 아니다.
- 실제 iOS/Android 기기, 스크린리더 음성, 장시간 GPU/배터리·FPS는 이번 검수 범위에 없다. 200% 검사는 CSS 글자 확대 재현이며 OS 확대 인증이 아니다.
- 운영 React/CSS, 게임 API/DB, 경제·전투 산식과 패키지 의존성은 변경하지 않았다. 커밋·푸시·본 게임 UI 이관은 수행하지 않았다.

## 재개

`npm run dev:solo -- --port 5180 --strictPort`로 정적 데모를 실행하고 `/uiux-demo/index.html`을 연다. 우측 상단 **시연 설정**에서 접근·출항·완료를 선택한다. 화면 설정의 **행성 자전 · 항로 움직임 정지**로 장식 모션을 멈출 수 있다.
